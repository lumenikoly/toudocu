Документационная модель готова для демонстрации. Основной сценарий находится в
работе, а переход во внешний центр поддержки уже описан как реализованный.

## Краткое состояние

Портал показывает документы всех основных типов, автономные Mermaid-диаграммы,
карту экранов с пятью видами переходов, два playable flow, raster preview,
fallback без изображения, hotspots и traceability рабочей задачи.

Активные задачи, блокеры и следующий результат автоматически выводятся в
HTML-представлении из work items и roadmap.
