# API-контракт

- Идентификатор: CON-CORE-API

REST-контракт между Web Frontend и Backend API. Все ответы имеют
`Content-Type: application/json`; время передаётся в UTC по RFC 3339.

## Создать обращение

`POST /api/v1/requests`

### Запрос

```json
{
  "title": "Не открывается отчёт",
  "description": "После входа страница отчёта возвращает ошибку."
}
```

| Поле | Тип | Обязательное | Ограничения |
|---|---|---|---|
| `title` | string | Да | От 3 до 120 символов |
| `description` | string | Да | От 10 до 4000 символов |

Неизвестные поля игнорируются для обратной совместимости в пределах API v1.

### Успешный ответ

`201 Created`

```json
{
  "id": "1f0f45a4-1f85-4aa7-9348-c4902f2537fd",
  "status": "new",
  "createdAt": "2026-07-29T18:00:00Z"
}
```

## Ошибки

| ID | Сообщение |
|---|---|
| `INVALID_INPUT` | Проверьте заполнение обязательных полей. |
| `UNSUPPORTED_MEDIA_TYPE` | Ожидается тело запроса в формате JSON. |
| `INTERNAL_ERROR` | Не удалось обработать обращение. |
| `STORAGE_UNAVAILABLE` | Хранилище временно недоступно. |

### Формат ошибки

Все ошибки имеют единую структуру:

```json
{
  "error": {
    "code": "INVALID_INPUT",
    "message": "Проверьте заполнение обязательных полей.",
    "fields": {
      "title": "Минимальная длина — 3 символа."
    }
  }
}
```

### HTTP-ответы

| HTTP | Код | Когда возвращается |
|---|---|---|
| `400` | `INVALID_INPUT` | Поля отсутствуют или нарушают ограничения |
| `415` | `UNSUPPORTED_MEDIA_TYPE` | Тело запроса не является JSON |
| `500` | `INTERNAL_ERROR` | Необработанная внутренняя ошибка |
| `503` | `STORAGE_UNAVAILABLE` | PostgreSQL временно недоступна |

При любом ответе, кроме `201`, обращение считается несозданным.

## Совместимость

- префикс `/api/v1` фиксирует major-версию;
- новые необязательные поля могут добавляться без смены major-версии;
- удаление поля или изменение его смысла требует новой major-версии.
