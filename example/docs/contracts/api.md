# API-контракт

- Идентификатор: CON-CORE-API

Описание стабильных входов, выходов и ошибок системы.

## Основная операция

### Вход

```json
{"value": "example"}
```

### Успешный результат

```json
{"result": "example"}
```

## Ошибки

| ID | Сообщение |
|---|---|
| `INVALID_INPUT` | Входные данные не прошли проверку. |
