# Границы доверия Service Desk

- Тип документа: Architecture
- Архитектурный вопрос: Где проходят границы доверия Service Desk?

Публичный браузер и внешний Support Center находятся вне доверенной зоны;
Backend API повторно проверяет каждый запрос на публичной HTTPS-границе, а
PostgreSQL и её учётные данные остаются в приватной зоне backend.

## Область

Ответ фиксирует зоны доверия целевого MVP. Конкретные ограничения полей и
ошибки принадлежат [API-контракту](../contracts/api.md).

## Публичная граница

Frontend не считается источником достоверных данных: локальная проверка
улучшает UX, но Backend независимо нормализует и валидирует запрос. Неуспешная
проверка не изменяет состояние PostgreSQL.

## Приватная граница

Только Backend API имеет SQL-доступ и секреты подключения. База данных не
публикуется в клиентскую сеть, а строки подключения не попадают в документацию
или frontend bundle.

## Внешний переход

Переход в Support Center обозначен как внешний HTTPS-маршрут и не передаёт
содержимое обращения. Навигационная связь описана в
[MOD-SUPPORT](../modules/support.md).
