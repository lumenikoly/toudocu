# Владение данными обращения

- Тип документа: Architecture
- Архитектурный вопрос: Кто владеет данными обращения и их изменением?

Backend API владеет смыслом и допустимыми изменениями обращения, PostgreSQL —
его зафиксированным состоянием, а Web Frontend — только пользовательским
черновиком до отправки и отображением подтверждённого результата.

## Область

Ответ описывает владение данными между компонентами, но не повторяет поля,
форматы ошибок или wire contract из [API-контракта](../contracts/api.md).

## Границы владения

- Frontend может собирать и предварительно проверять введённые значения, но не
  назначает серверные `id`, `status` и время создания.
- Backend повторно проверяет вход, применяет `BR-CORE-001` и `BR-CORE-002` и
  является единственным компонентом, инициирующим изменение хранимого
  обращения.
- PostgreSQL подтверждает фиксацию транзакции; успешный ответ API означает, что
  это состояние сохранено.
- Support Center не получает данные создаваемого обращения.

Правила и инварианты владельца бизнес-операции определены в
[MOD-CORE](../modules/core.md).
