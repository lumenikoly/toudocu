Пользователь получает основной результат проекта.

## Входные данные

- Валидный пользовательский запрос.

## Предусловия

- Система доступна.

## Основной сценарий

1. Пользователь открывает форму нового запроса.
2. При необходимости пользователь открывает и закрывает контекстную подсказку.
3. Пользователь отправляет запрос.
4. Система проверяет входные данные.
5. Система возвращает результат.

## Ошибочные сценарии

При неверных данных система возвращает понятную ошибку и не изменяет состояние.

## Постусловия

При успехе результат создан; при ошибке состояние не изменено.

## Бизнес-правила

- BR-CORE-001 — правило проверки входных данных.
