# UC-CORE-02: Открыть центр поддержки

- Идентификатор: UC-CORE-02
- Статус: Реализован
- Актор: Пользователь
- Модуль: MOD-CORE
- Начальный экран: SC-CORE-HOME
- Конечные экраны: SC-SUPPORT-PORTAL
- Экраны: SC-CORE-HOME, SC-SUPPORT-PORTAL
- Приоритет: Средний
- Последнее обновление: 2026-07-29

Пользователь переходит из Service Desk во внешний центр поддержки.

## Входные данные

- действие «Открыть центр поддержки».

## Предусловия

- главная страница Service Desk доступна.

## Основной сценарий

1. Пользователь выбирает центр поддержки.
2. Система открывает внешнюю HTTPS-страницу.

## Постусловия

Пользователь находится во внешнем центре поддержки.

## Бизнес-правила

- внешний URL объявляется только у экрана типа `Внешняя страница`.
