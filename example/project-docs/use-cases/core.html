Пользователь получает основной результат проекта.

#Входные данные

  • Валидный пользовательский запрос.

#Предусловия

  • Система доступна.

#Основной сценарий

  1. Пользователь отправляет запрос.
  2. Система проверяет входные данные.
  3. Система возвращает результат.

#Ошибочные сценарии

При неверных данных система возвращает понятную ошибку и не изменяет состояние.

#Постусловия

При успехе результат создан; при ошибке состояние не изменено.

#Бизнес-правила

  • BR-CORE-001 — правило проверки входных данных.
