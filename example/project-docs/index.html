Service Desk Showcase

Демонстрационный проект показывает возможности Docgent на документации небольшого сервиса обращений: от модели требований и задач до интерактивной карты экранов и проигрываемых сценариев.

Портал показывает документы всех основных типов, единый каталог UC- и FLOW- , автономные Mermaid-диаграммы, карту экранов с пятью видами переходов, два проигрываемых сценария, raster preview, fallback без изображения, hotspots и traceability рабочей задачи. Активные задачи, блокеры и следующий результат автоматически выводятся в HTML-представлении из work items и roadmap.

Интерактивный прототип · 0.1.0 · Команда проекта · 2026-07-29

Демонстрационный проект показывает возможности Docgent на документации небольшого сервиса обращений: от модели требований и задач до интерактивной карты экранов и проигрываемых сценариев.

#Проблема

Пользователю нужен понятный способ создать обращение, исправить ошибочные данные и при необходимости перейти во внешний центр поддержки.

#Решение

Web Frontend принимает данные обращения, Backend API проверяет бизнес-правила, а PostgreSQL сохраняет результат. Каждый пользовательский переход документируется стабильными SC-*, TR-* и UC-*.

#Основные возможности

  • связанная модель модулей, use cases, бизнес-правил и контрактов;
  • трёхслойная архитектура Web Frontend, Backend API и PostgreSQL;
  • roadmap, риски, решения и рабочие задачи;
  • Mermaid flowchart, state diagram и sequence diagram;
  • самостоятельный раздел пользовательских сценариев и полный сводный каталог

процессов с UC-*, FLOW-* и связью одного процесса с несколькими сценариями;

  • каталог экранов, Screen Map, sitemap и все типы SVG-переходов;
  • два проигрываемых сценария, состояния, ошибки, previews и hotspots;
  • traceability от критерия приёмки до перехода и проверки.

#Целевая аудитория

Пример предназначен разработчикам, тестировщикам, аналитикам и AI-агентам, которым нужно быстро увидеть полный результат работы Docgent.

#Ограничения

  • это демонстрация документации, а не работающий backend;
  • пошаговый viewer не выполняет реальные API-запросы.
