Внешняя поддержка

Модуль описывает границу перехода из Service Desk во внешний Support Center.

Идентификатор
MOD-SUPPORT

Модуль описывает границу перехода из Service Desk во внешний Support Center.

#Назначение

Сделать внешнюю точку поддержки видимой в карте пользовательской навигации.

#Расположение в коде

  • Интеграция: docs/screens/SC-SUPPORT-PORTAL.md

#Границы

Docgent проверяет только HTTPS-маршрут и связь с экраном. Содержимое внешней системы не входит в модель проекта.

#Бизнес-правила

#BR-SUPPORT-001: Внешний переход явно обозначается на карте

Связь с Support Center отображается двойной направленной линией.

#Инварианты

  • внешний экран имеет HTTP(S)-маршрут;
  • переход не выполняет JavaScript из документации.

#Стабильные интерфейсы

  • маршрут https://support.example.com/.
