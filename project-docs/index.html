Docgent

Docgent — dependency-free CLI на Go для проверяемой проектной документации в структурированном Markdown и автономного HTML-портала, работающего через file:// .

CLI проверяет, собирает и локально раздаёт документацию, формирует типизированные JSON-отчёты, выдаёт контекст выбранной задачи и выполняет её проверки только по явной команде. Встроенная Mermaid Tiny отображает связанные процессы без CDN или Node.js. Безопасность путей, HTML, диаграмм, HTTP-раздачи и process timeout проверяется негативными тестами. Модель процессов формирует единый каталог UC- и FLOW- , стабильные URL по ID и рабочее пространство use case с описанием, картой, проигрыванием и связями. Экранная модель формирует каталог, общую карту с SVG-связями, sitemap, hotspots и traceability. Всё работает через file:// , поддерживает клавиатуру, touch, состояния, ошибки и fallback без preview. Активные задачи, блокеры и следующий результат вычисляются из work items и roadmap и отображаются в HTML автоматически.

Полная реализация документной модели и визуального портала · 1.1.0-go · Команда Docgent · 2026-07-29

Docgent — dependency-free CLI на Go для проверяемой проектной документации в структурированном Markdown и автономного HTML-портала, работающего через file://.

#Проблема

Проектная документация быстро расходится с кодом, когда статусы, связи, критерии приёмки и команды проверки хранятся в несогласованных файлах или требуют ручной синхронизации.

#Решение

Docgent строит единую модель из Markdown, проверяет стабильные идентификаторы, ссылки, бизнес-правила, roadmap и work items, а затем отдаёт результат человеку в HTML и автоматизации в JSON ProjectReport schema v2.

#Основные возможности

  • минимальный старт с единственного docs/index.md;
  • строгая структурная и ссылочная валидация;
  • вычисляемое состояние roadmap и активной работы;
  • самостоятельный раздел UC-* и полный сводный каталог процессов с FLOW-*

и двусторонними связями;

  • автономные Mermaid-диаграммы и типизированные FLOW-* процессы;
  • типизированный каталог SC-*, интерактивная карта и проигрываемые сценарии;
  • traceability UC → SC → TR → TASK → AC → verification;
  • безопасный статический HTML с поиском, темами и адаптивной навигацией;
  • компактный read-only контекст задачи для LLM-агента;
  • выполнение явно объявленных проверок выбранной задачи;
  • versioned JSON schema для проекта, task context и task workflow;
  • работа одним бинарником без внешних Go- и runtime-зависимостей.

#Целевая аудитория

  • разработчики и технические руководители;
  • команды, ведущие документацию рядом с кодом;
  • LLM-агенты, которым нужен ограниченный и машиночитаемый контекст;
  • CI-системы, проверяющие документационный контракт.

#Ограничения

  • поддерживается намеренно ограниченное подмножество Markdown;
  • команды task verify --run считаются доверенным кодом репозитория;
  • портал является статическим и не редактирует исходные документы;
  • глобальный прогресс определяется только roadmap.md.
