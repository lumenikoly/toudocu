UC-TASK-03 · Подготовить новую рабочую задачу

Исполнитель находит релевантные документы, создаёт нейтральный каркас задачи и доводит её контракт до состояния, пригодного для ручного перевода в Ready.

Исполнитель находит релевантные документы, создаёт нейтральный каркас задачи и доводит её контракт до состояния, пригодного для ручного перевода в Ready.

#Входные данные

  • пользовательский запрос;
  • каталог документации;
  • область, заголовок и тип задачи;
  • необязательный язык каркаса.

#Предусловия

  • Docgent доступен для запуска;
  • каталог документации существует;
  • исполнитель самостоятельно интерпретировал запрос и выбрал сущности.

#Основной сценарий

  1. Исполнитель вызывает docgent search и изучает подходящие исходные документы.
  2. Исполнитель вызывает docgent task init с явными area, title и type.
  3. При необходимости исполнитель создаёт выбранные сущности через scaffold.
  4. Исполнитель заполняет scope, out of scope, изменение поведения, критерии,

план, verification mappings и documentation impact.

  1. Исполнитель вызывает docgent task ready TASK-ID.
  2. Для полного Draft Docgent возвращает contract_ready, не изменяя Markdown.
  3. Исполнитель проверяет смысл контракта и вручную меняет статус на Ready.
  4. Повторный task ready возвращает ready.

#Ошибочные сценарии

  • невалидные type, language, ID или limit завершают команду с кодом 1;
  • существующий целевой файл не перезаписывается;
  • неполный контракт возвращает contract_incomplete;
  • связанная ошибка документации блокирует readiness;
  • статус кроме Draft или Ready возвращает invalid_state.

#Постусловия

Каркас создан без вымышленных связей или требований. Только исполнитель интерпретирует запрос, заполняет смысловые поля и меняет статус задачи.

#Бизнес-правила

  • BR-CLI-004 — Docgent не выбирает сущности и не меняет статус.
  • BR-MODEL-003 — readiness проверяет полный контракт.

#Реализация

  • FLOW-TASK-WORKFLOW
  • ADR-002
  • CLI-контракт

#Проверка

  • тесты search ranking и нормализации;
  • тесты atomic create и allocation TASK ID;
  • тесты readiness для Draft и Ready.
