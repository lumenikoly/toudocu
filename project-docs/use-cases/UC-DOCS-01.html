UC-DOCS-01 · Создать автономный портал

Разработчик преобразует каталог проектной документации в статический портал, который можно открыть с диска без HTTP-сервера.

Разработчик преобразует каталог проектной документации в статический портал, который можно открыть с диска без HTTP-сервера.

#Входные данные

  • каталог проектной документации;
  • выходной каталог;
  • необязательные настройки repository URL, ref, excludes и stale threshold.

#Предусловия

  • Docu-docu доступен для запуска;
  • у разработчика есть права чтения исходного каталога и записи в выходной.

#Основной сценарий

  1. Разработчик вызывает docu-docu build ./docs --output ./build/project-docs.
  2. Docu-docu читает документы и проверяет структуру, ссылки и связанные сущности.
  3. Docu-docu создаёт HTML-страницы, ресурсы поиска и report.json.
  4. Docu-docu сообщает путь к созданному index.html и итоговую статистику.
  5. Разработчик открывает index.html через file://.

#Ошибочные сценарии

  • на шаге 2 недоступный исходный каталог завершает команду с кодом 1, портал

не создаётся;

  • перед шагом 3 небезопасный путь --output или --clean отклоняется до

удаления и записи файлов;

  • если модель содержит ошибки, портал и report.json создаются с diagnostics,

а команда завершается с кодом 1;

  • при --strict наличие предупреждений также приводит к коду 1;
  • ошибка записи или генерации прерывает сборку и выводится в stderr.

#Постусловия

При успешной генерации выходной каталог содержит автономный портал и ProjectReport schema v1. Исходный Markdown не изменён.

#Бизнес-правила

Правила определены в документах соответствующих модулей:

  • BR-SITE-001 — очистка output не затрагивает защищённые каталоги.
  • BR-SITE-002 — портал работает через file protocol.
  • BR-MD-001 — пользовательский HTML всегда экранируется.
  • BR-MD-002 — опасные протоколы и активные assets блокируются.
  • BR-MD-003 — Mermaid остаётся визуализацией.
  • BR-SITE-004 — Mermaid работает автономно и в строгом режиме.

#Реализация

  • FLOW-DOCS-BUILD: Сборка автономного портала
  • Статический портал
  • Безопасный Markdown
  • CLI-контракт

#Проверка

  • интеграционная генерация HTML и JSON;
  • негативные тесты output, симлинков и активных assets;
  • сборка минимального проекта с index.md и architecture/overview.md;
  • открытие внутренних ссылок без HTTP-сервера.
