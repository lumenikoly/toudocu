#Результат

На страницах исходных Markdown-документов пользователь может одним действием скопировать название и repository-relative путь, чтобы передать точный контекст агенту.

#Изменение поведения

#Было

Портал позволял копировать блоки кода, но не предоставлял короткую ссылку на исходный документ открытой страницы.

#Станет

Обычные страницы документов, канонические страницы use case и главный dashboard для index.md содержат кнопку «Копировать контекст». В буфер записываются две строки:

text
Документ: <название>
Путь: <путь от repository-root>

#Область изменения

  • site.go;
  • process_site.go;
  • assets/app.js;
  • assets/style.css;
  • тесты генерации портала;
  • исходная документация модуля и каталога возможностей.

#Не входит в задачу

  • копирование полного содержимого документа;
  • кнопка на каталогах, Screen Map, traceability и health page;
  • изменение CLI, Go API или report.json schema v1;
  • новые зависимости.

#Критерии приёмки

  • ✓AC-01 Обычный документ, use case и dashboard копируют название и

repository-relative путь в согласованном двухстрочном формате.

  • ✓AC-02 Каталоги и служебные страницы не получают кнопку контекста.
  • ✓AC-03 Копирование работает через Clipboard API и автономный fallback для

file://, сообщает результат и доступно с клавиатуры.

  • ✓AC-04 Путь не раскрывает абсолютное расположение документа; вне

repository-root используется безопасный SourcePath.

#План

  • ✓Добавить безопасное вычисление контекста и HTML-кнопку.
  • ✓Подключить кнопку ко всем source-backed страницам выбранного охвата.
  • ✓Реализовать browser copy, состояния и адаптивные стили.
  • ✓Обновить документацию и тесты.
  • ✓Выполнить полный verification cycle и пересобрать отслеживаемый портал.

#Проверка

  • AC-01 → go test ./... -run 'TestGenerateSite|TestDocumentContext'
  • AC-02 → go test ./... -run 'TestDocumentContext'
  • AC-03 → go test ./... -run 'TestDocumentContext'
  • AC-04 → go test ./... -run 'TestDocumentContext'
  • ALL → go test ./...
  • DOCS → go run ./cmd/docgent check ./docs --repository-root .

#Влияние на документацию

Обновляются описание модуля и каталог возможностей. Отслеживаемый портал пересобирается из исходного Markdown после завершения проверки.
