ADR-003: Supported YAML parser for OpenAPI diff

Docu-docu uses one fixed pure-Go YAML module for correct OpenAPI diff, keeping delivery as one self-contained binary.

Статус
Accepted
Автор
Docu-docu Team
Дата
2026-07-31
Последнее обновление
2026-07-31
Идентификатор
ADR-003

Docu-docu uses one fixed pure-Go YAML module for correct OpenAPI diff, keeping delivery as one self-contained binary.

#Context

The existing parser .docu-docu/config.yml only supports a small set YAML. OpenAPI requires mappings, sequences, anchors, aliases, flow values and exact source locations; independent implementation of a complete parser increased would be a risk of errors and a security surface.

#Decision

Pin go.yaml.in/yaml/v3 version v3.0.5, decode OpenAPI to yaml.Node, limit size, depth, aliases and internal $ref, not download external references. The dependency is accompanied by go.sum, notices, license and regular inspection by advisories.

#Consequences

  • runtime remains offline and is supplied by one Go binary;
  • ADR-001's statement about the absence of any Go modules gets this narrow

exception;

  • OpenAPI YAML and JSON receive a single typed tree with line/column;
  • updating the YAML module requires a separate review of compatibility and security.
