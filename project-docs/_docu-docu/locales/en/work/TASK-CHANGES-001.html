#Result

docu-docu changes and the /changes section show Git changes to the original documentation like source, rendered and deterministic semantic diff compare them with task impact and export ChangeSetReport schema v1.

#Behavior change

#Before

The portal shows only the current state, and review uses an external git diff without project semantics and task impact.

#After

serve provides a read-only Changes workspace with an explicit range, lazy specialized views and live invalidation. CLI and CI get the same report without changing Git.

#Scope

  • public facade api.go and internal/app/cli.go, internal/app/types.go, internal/app/site_config.go;
  • internal/app/server.go, internal/app/site.go, internal/app/screen_site.go;
  • internal/app/assets/, package.json, package-lock.json;
  • go.mod, go.sum, THIRD_PARTY_NOTICES.md;
  • tests in internal/app/;
  • docs/, README.md, CHANGELOG.md;
  • project-docs/, example/project-docs/ only through rebuilding.

#Out of scope

  • changing Git index, history, refs or working tree;
  • fetch, checkout, commit, merge, rebase and GitHub PR API;
  • inline review comments, approvals and conflict editor;
  • AI-generated summaries and documentation correction;
  • pixel diff Mermaid or images;
  • Git diff source code outside documentation roots.

#Acceptance criteria

  • ✓AC-01 Git adapter supports commit, index and working-tree snapshots,

staged/unstaged/untracked, rename/copy/type change and Unicode paths without shell, external diff, textconv, hooks or fetch.

  • ✓AC-02 ChangeSetReport schema v1 contains an explicit resolved comparison,

digest, file/entity summaries, changes, task impact and diagnostics.

  • ✓AC-03 Unified diff is exactly derived from Git, side-by-side is derived from hunks,

and large or binary files do not block change set.

  • ✓AC-04 Deterministic semantic diff supports UC, FLOW, SC/TR, MOD,

ADR, TASK, Architecture and relations, ignoring minor formatting.

  • ✓AC-05 OpenAPI YAML/JSON diff compares operations, requests, responses,

schemas and security and classifies compatibility.

  • ✓AC-06 Rendered Markdown, Mermaid, Screen Map and image assets available until

and after isolating the error of one side.

  • ✓AC-07 Task impact separates task contract from permanent documentation and

returns declared/actual/scope diagnostics.

  • ✓AC-08 CLI supports summary, file and task reports, filters,

text/JSON/Markdown/output and exit codes 0–4.

  • ✓AC-09 Read-only HTTP API checks revisions/paths/limits, supports

lazy detail, ETag and live digest update.

  • ✓AC-10 Changes UI supports comparison selector, filters/search,

unified/merge/rendered/semantic/specialized tabs, deep links and accessibility.

  • ✓AC-11 serve saves filters/open file with invalidation, and absence

Git shows diagnostic and does not break the rest of the portal.

  • ✓AC-12 Static build, existing check, ProjectReport schema v1 and

editor workflows remain compatible and pass regression tests.
