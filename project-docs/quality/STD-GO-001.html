Стандарт сохраняет реализацию Docu-docu небольшой, предсказуемой, dependency-free и проверяемой на поддерживаемых Go-платформах.

STD-GO-001

Стандарт сохраняет реализацию Docu-docu небольшой, предсказуемой, dependency-free и проверяемой на поддерживаемых Go-платформах.

#Правила

  1. Не добавлять внешнюю зависимость без доказанной необходимости.
  2. Публичные операции вызываются только явными командами; путь без команды не

запускает неявный build.

  1. Каждое новое правило валидации сопровождать поведенческим тестом.
  2. Каждое исправление безопасности сопровождать негативным тестом.
  3. Не ослаблять проверки repository-root и безопасного --clean.
  4. Сохранять обычные check, build, serve и task context

неисполняющими команды work item.

#Автоматические проверки

  • gofmt -w .;
  • go vet ./...;
  • go test ./...;
  • go test -race ./....

Команды запускаются из work item или доверенного CI workflow, а не напрямую из этого стандарта.
