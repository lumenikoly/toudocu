ADR-001: Dependency-free Go CLI

Docgent поставляется одним Go-бинарником и не использует внешние модули или runtime-зависимости.

ADR-001

Docgent поставляется одним Go-бинарником и не использует внешние модули или runtime-зависимости.

#Контекст

Инструмент должен работать в локальном репозитории, CI и агентском окружении без npm, сервера и установки дополнительного Markdown runtime. Одновременно нужны безопасный HTML и предсказуемая работа через file://.

#Решение

Использовать только стандартную библиотеку Go, go:embed для assets, а также собственное ограниченное подмножество Markdown. Browser-only библиотеки допускаются как закреплённые vendored assets, если они не требуют runtime, сети или внешних файлов и сопровождаются лицензией и security-процессом.

Новая внешняя зависимость допускается только после доказательства, что её ценность превышает влияние на поставку, поверхность атаки и сопровождение.

#Причины

  • один воспроизводимый артефакт для всех поддерживаемых платформ;
  • отсутствие package installation и сетевого доступа во время работы;
  • полный контроль над экранированием и локальными ссылками;
  • простой deployment в существующий репозиторий.

#Последствия

#Положительные

  • минимальная эксплуатационная сложность;
  • быстрый запуск и простая cross-compilation;
  • отсутствие supply-chain зависимостей приложения;
  • assets доступны без соседних файлов.
  • Mermaid-диаграммы доступны без Node.js, CDN и обязательного HTTP-сервера.

#Отрицательные

  • Markdown parser и renderer поддерживаются внутри проекта;
  • совместимость с полным CommonMark не гарантируется;
  • безопасность каждого нового Markdown-конструкта требует собственных тестов;
  • часть кода для CLI, HTML и process management нельзя делегировать библиотеке.
  • обновление vendored Mermaid требует отдельной проверки лицензии, checksum,

file://-совместимости и security advisories.

#Статус пересмотра

Решение пересматривается, если собственный Markdown subset становится основным источником дефектов или внешняя зависимость существенно уменьшает код при сохранении автономной поставки.
