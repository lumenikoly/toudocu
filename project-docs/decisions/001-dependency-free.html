ADR-001: Dependency-free Go CLI

Docu-docu поставляется одним Go-бинарником и не требует runtime-зависимостей. Pure-Go исключения для внешних Go modules зафиксированы в ADR-003 и ADR-005; они не добавляют сеть либо соседние runtime-файлы.

Docu-docu поставляется одним Go-бинарником и не требует runtime-зависимостей. Pure-Go исключения для внешних Go modules зафиксированы в ADR-003 и ADR-005; они не добавляют сеть либо соседние runtime-файлы.

#Контекст

Инструмент должен работать в локальном репозитории, CI и агентском окружении без npm и установки дополнительного Markdown runtime. Одновременно нужны безопасный HTML, backend-independent static output и локальный HTTP runtime.

#Решение

Использовать преимущественно стандартную библиотеку Go, go:embed для assets, а для Markdown — закрытый за собственной моделью pure-Go движок по ADR-005. Browser-only библиотеки допускаются как закреплённые vendored assets, если они не требуют runtime, сети или внешних файлов и сопровождаются лицензией и security-процессом.

Новая внешняя зависимость допускается только после ADR с доказательством, что её ценность превышает влияние на поставку, поверхность атаки и сопровождение.

#Причины

  • один воспроизводимый артефакт для всех поддерживаемых платформ;
  • отсутствие package installation и сетевого доступа во время работы;
  • полный контроль над экранированием и локальными ссылками;
  • простой deployment в существующий репозиторий.

#Последствия

#Положительные

  • минимальная эксплуатационная сложность;
  • быстрый запуск и простая cross-compilation;
  • отсутствие runtime package installation и сетевой загрузки зависимостей;
  • assets доступны без соседних файлов.
  • Mermaid-диаграммы доступны без Node.js, CDN и внешнего backend; для browser runtime используется static HTTP hosting или встроенный serve.

#Отрицательные

  • Markdown policy, нормализованная модель и safe renderer остаются ответственностью проекта;
  • обновление Markdown dialect или Goldmark требует corpus и security review;
  • часть кода для CLI, HTML и process management нельзя делегировать библиотеке.
  • обновление vendored Mermaid требует отдельной проверки лицензии, checksum, static HTTP compatibility и security advisories.

#Статус пересмотра

Решение пересматривается, если закреплённые pure-Go зависимости перестают сохранять автономную поставку либо их сопровождение и поверхность атаки становятся несоразмерны пользе.
