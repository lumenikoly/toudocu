# Contributing

Спасибо за вклад в Docgent.

## Процесс

1. Создайте небольшую ветку с одной логической целью.
2. Добавьте или обновите тесты.
3. Выполните форматирование и полный набор проверок.
4. Обновите README и проектную документацию, если изменилось пользовательское поведение.
5. В pull request опишите наблюдаемое изменение и способ проверки.

## Проверки

```bash
gofmt -w .
go vet ./...
go test ./...
go test -race ./...
```

Не добавляйте тяжёлые фреймворки или скрытые runtime-зависимости. Пользовательская установка должна оставаться одним бинарником.
