# ADR-005: Goldmark как единственный Markdown-движок

Toudocu использует закреплённый Go-модуль Goldmark `v1.8.5` для разбора и
отрисовки Markdown. Собственная модель документов и правила безопасности
остаются внутри проекта.

<!-- toudocu:section context -->
## Контекст

Прежний разбор по строкам и регулярным выражениям по-разному понимал вложенные
списки, экранирование, блоки кода и элементы внутри строки. Таблицы, Mermaid и
семантическое сравнение повторно разбирали один текст несколькими способами.
Нужен один источник структуры, но типы сторонней библиотеки не должны попасть в
публичный Go API и JSON версии 1.

<!-- toudocu:section decision -->
## Решение

Использовать `github.com/yuin/goldmark v1.8.5` с ядром, совместимым с CommonMark
0.31.2, и встроенными расширениями Table, TaskList, Strikethrough и Linkify.
`internal/markdown` владеет всем путём `Parse → Analysis → Render`, позициями в
исходнике и закрытым деревом Goldmark. Toudocu сам создаёт ID заголовков,
нормализованную модель, безопасные ссылки и специальные элементы портала.

Сырой HTML и завершённый front matter в начале файла считаются ошибкой
политики. Предварительный просмотр и сравнение показывают их как экранированный
текст. Небезопасный режим HTML, attributes, footnotes, definition lists,
typographer и сторонние расширения не включены. Mermaid распознаётся только по
слову `mermaid` в строке типа блока и проходит отдельные строгие правила.

Низкоуровневые операции Goldmark не экспортируются. Публичными остаются
операции модели, отчёта, портала и задач; JSON версии 1 не меняется.

<!-- toudocu:section consequences -->
## Последствия

- Поддерживаемый CommonMark и GFM получают одно дерево разбора.
- Заголовки, таблицы, задачи и блоки кода больше не ищутся разными парсерами.
- Обновление Goldmark требует проверки корпуса документов, безопасности,
  семантики и сборки на поддерживаемых платформах.
- Точный HTML и пробелы могут измениться без изменения проектной модели.
- Модуль компилируется внутрь бинарника и не добавляет сеть, CGO или соседний
  файл.
