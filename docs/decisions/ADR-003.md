# ADR-003: Поддерживаемый YAML parser для OpenAPI diff

- Идентификатор: ADR-003
- Статус: Принято
- Дата: 2026-07-31
- Автор: Команда Toudocu
- Последнее обновление: 2026-07-31

Toudocu использует один закреплённый pure-Go YAML module для корректного
OpenAPI diff, сохраняя поставку одним автономным бинарником.

## Контекст

Существующий parser `.toudocu/config.yml` поддерживает только небольшой набор
YAML. OpenAPI требует mappings, sequences, anchors, aliases, flow values и
точные source locations; самостоятельная реализация полного parser увеличила
бы риск ошибок и поверхность безопасности.

## Решение

Закрепить `go.yaml.in/yaml/v3` версии `v3.0.5`, декодировать OpenAPI в
`yaml.Node`, ограничивать размер, глубину, aliases и internal `$ref`, не
загружать external references. Зависимость сопровождается `go.sum`, notices,
лицензией и регулярной проверкой advisories.

## Последствия

- runtime остаётся offline и поставляется одним Go binary;
- утверждение ADR-001 об отсутствии любых Go modules получает это узкое
  исключение;
- OpenAPI YAML и JSON получают единый typed tree с line/column;
- обновление YAML module требует отдельного review совместимости и безопасности.
