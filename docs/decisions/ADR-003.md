# ADR-003: Готовый YAML-парсер для OpenAPI

- Идентификатор: ADR-003
- Статус: Принято
- Дата: 2026-07-31
- Автор: Команда Toudocu
- Последнее обновление: 2026-08-10

Для корректного сравнения OpenAPI Toudocu использует один закреплённый
Go-модуль YAML. Он компилируется внутрь автономного бинарника.

## Контекст

Собственный разбор `.toudocu/config.yml` поддерживает только нужное проекту
подмножество YAML. OpenAPI использует вложенные объекты и списки, якоря,
псевдонимы, компактную запись значений и точные позиции. Реализация всего этого
в проекте была бы сложнее и опаснее готового проверенного парсера.

## Решение

Использовать `go.yaml.in/yaml/v3` версии `v3.0.5` и декодировать OpenAPI в
`yaml.Node`. Ограничивать размер, глубину, псевдонимы и внутренние `$ref`;
внешние ссылки никогда не загружать. Версия, лицензия и контрольные сведения
фиксируются в репозитории, а обновление требует проверки advisories.

## Последствия

- Во время работы сеть по-прежнему не нужна, поставка остаётся одним бинарником.
- ADR-001 получает одно явно описанное исключение для Go-модуля.
- YAML и JSON OpenAPI преобразуются в одну структуру с номерами строк и колонок.
- Обновление модуля требует отдельной проверки совместимости и безопасности.
