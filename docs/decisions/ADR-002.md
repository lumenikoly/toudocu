# ADR-002: Граница ответственности Agent и Toudocu

- Идентификатор: ADR-002
- Статус: Принято
- Дата: 2026-07-29
- Автор: Команда Toudocu
- Последнее обновление: 2026-07-29

Решение фиксирует границу между детерминированной механикой CLI и смысловой
работой исполнителя.

## Контекст

Подготовка задачи начинается с естественного языка, но документационная модель
должна оставаться воспроизводимой и проверяемой без LLM или сетевого сервиса.
Автоматическое создание связей, требований и статусов сделало бы каркас
недостоверным источником истины.

## Решение

Toudocu выполняет только детерминированные операции: лексический поиск,
выделение ID, создание нейтральных каркасов, структурную readiness-проверку,
сбор контекста и явный запуск объявленных verification-команд.

Исполнитель интерпретирует запрос, выбирает сущности, заполняет документы,
формулирует требования и критерии, меняет статусы и отмечает `[x]` только после
фактического evidence. Toudocu не выполняет эти действия автоматически.

## Последствия

- CLI остаётся dependency-free и воспроизводимым;
- каркасы не выдумывают связи, topology или бизнес-правила;
- readiness остаётся read-only;
- качество смысла требует агентской или человеческой проверки;
- natural-language orchestration находится вне публичного контракта Toudocu.
