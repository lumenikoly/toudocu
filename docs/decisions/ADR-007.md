# ADR-007: Serve-only подсветка repository review

- Идентификатор: ADR-007
- Статус: Принято
- Дата: 2026-08-09
- Автор: Команда Toudocu
- Последнее обновление: 2026-08-09

Решение ограничивает serve-only syntax highlighting четырьмя семействами
языков и сохраняет plain-text fallback для остальных UTF-8 repository files.

## Контекст

Changes показывает Markdown и произвольные repository files. Существующий
CodeMirror bundle умеет Markdown, JSON и YAML, но review кода нуждается в
читаемой подсветке без CDN и без новой runtime-зависимости Go. Подключение всех
языков увеличило бы serve-only bundle и поверхность сопровождения.

## Решение

Закрепить прямые зависимости `@codemirror/lang-go@6.0.1`,
`@codemirror/lang-java@6.0.2` и
`@codemirror/lang-javascript@6.2.5`. Последняя обслуживает JavaScript, JSX,
TypeScript и TSX через явный dialect. Остальные валидные UTF-8 файлы открываются
в read-only plain-text viewer с тем же selection contract.

Языковые packages встраиваются только в serve-only CodeMirror IIFE из `web/`.
Generated bundle, license notice и checksum обновляются build script; static
manifest CodeMirror не получает.

## Последствия

- Go, Java, JavaScript и TypeScript имеют syntax highlighting в merge/file
  viewer, но anchor coordinates остаются языконезависимыми;
- plain-text fallback сохраняет review любого UTF-8 файла без ложного parser;
- bundle становится больше, зато остаётся offline и воспроизводимым;
- версии и notices обновляются только осознанным frontend dependency change.
