# ADR-007: Подсветка кода только в `serve`

В разделе изменений подсветка кода ограничена Go, Java, JavaScript и
TypeScript. Остальные текстовые файлы остаются обычным UTF-8 текстом.

<!-- toudocu:section context -->
## Контекст

Раздел «Изменения» показывает и Markdown, и произвольные файлы репозитория.
CodeMirror уже поддерживает Markdown, JSON и YAML, но для чтения кода нужна
подсветка без CDN и новой зависимости Go. Включение всех языков заметно
увеличило бы встроенный пакет и стоимость обновлений.

<!-- toudocu:section decision -->
## Решение

Закрепить прямые зависимости `@codemirror/lang-go@6.0.1`,
`@codemirror/lang-java@6.0.2` и
`@codemirror/lang-javascript@6.2.5`. Последняя поддерживает JavaScript, JSX,
TypeScript и TSX в явно выбранном режиме. Любой другой корректный UTF-8 файл
открывается в редакторе только для чтения без языкового парсера; выделение и
комментарии работают так же.

Языковые пакеты входят только в CodeMirror-ресурс режима `serve`. Сценарий
сборки обновляет производный файл, сведения о лицензиях и контрольную сумму;
статический портал эти пакеты не получает.

<!-- toudocu:section consequences -->
## Последствия

- Go, Java, JavaScript и TypeScript читаются с подсветкой, но координаты
  комментария от языка не зависят.
- Любой другой UTF-8 файл всё равно можно просмотреть и прокомментировать.
- Встроенный ресурс становится больше, но остаётся автономным и
  воспроизводимым.
- Версии и лицензии обновляются только вместе с осознанным изменением
  зависимостей интерфейса.
