# UC-TASK-01: Работать с выбранной задачей

- Идентификатор: UC-TASK-01
- Статус: Готово
- Актор: LLM-агент или разработчик
- Модуль: MOD-CLI
- Приоритет: Высокий
- Последнее обновление: 2026-07-26

Агент получает ограниченный контекст одной задачи, выполняет изменение и затем
явно запускает объявленные проверки.

## Входные данные

- стабильный `TASK-*` ID;
- каталог документации и repository root;
- для проверки — timeout и опциональный путь JSON-отчёта.

## Предусловия

- задача существует ровно в одном `work/TASK-*.md`;
- перед реализацией задача переведена как минимум в `Готово к работе`;
- команды проверки доверены владельцем репозитория.

## Основной сценарий

1. Агент вызывает `docgent task context TASK-ID ./docs --format json`.
2. CLI возвращает задачу, модуль, use case, правила, зависимости и diagnostics.
3. Агент изменяет только заявленный scope.
4. Агент вызывает `docgent task check TASK-ID ./docs --format json`.
5. Валидатор применяет task-local gate и последовательно запускает уникальные
   команды.
6. Агент использует exit code и `TaskCheckReport` как проверяемый результат.

## Ошибочные сценарии

- отсутствующий или неоднозначный ID отклоняется;
- ошибка документа выбранной задачи блокирует выполнение команд;
- ошибка отдельной команды не останавливает остальные проверки;
- превышение timeout завершает дерево процессов и фиксируется в отчёте.

## Постусловия

Контекст не имеет побочных эффектов. После проверки доступен schema v1 отчёт с
командами, targets, критериями, exit codes, длительностями и ограниченным
выводом.

Правила определены в документах соответствующих модулей:

- [BR-CLI-001](../modules/cli.md#br-cli-001-контекст-задачи-не-исполняет-команды) — контекст задачи не исполняет команды.
- [BR-CLI-002](../modules/cli.md#br-cli-002-проверки-запускаются-только-явно) — проверки запускаются только явно.
- [BR-CLI-003](../modules/cli.md#br-cli-003-timeout-завершает-дерево-процессов) — timeout завершает дерево процессов.

- JSON-тест компактного task context без исполнения;
- fake runner для дедупликации, ошибок и timeout;
