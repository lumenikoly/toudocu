# UC-DOCS-04: Исследовать карту экранов

- Идентификатор: UC-DOCS-04
- Статус: Готово
- Актор: Разработчик
- Модуль: MOD-SITE
- Приоритет: Высокий
- Последнее обновление: 2026-07-28

Разработчик проверяет структуру экранов и исследует пользовательскую навигацию
в автономном портале.

## Входные данные

- `screens/map.md` с каталогом и переходами;
- необязательные документы `screens/SC-*.md`;
- ссылки на `SC-*` из use cases и work items.

## Предусловия

- карта содержит хотя бы один экран `entry`;
- каждый экран связан с существующим модулем.

## Основной сценарий

1. Разработчик запускает `check` или `build`.
2. Docgent проверяет таблицы, идентификаторы, ссылки и топологию.
3. Портал строит Mermaid-карту и каталог из одной модели.
4. Разработчик фильтрует экраны либо выбирает два экрана для просмотра всех
   ведущих между ними веток.
5. Разработчик открывает связанный документ экрана, use case или задачу.

## Ошибочные сценарии

- неизвестный `SC-*`, модуль или тип делает модель ошибочной;
- изоляция и недостижимость остаются предупреждениями;
- при отсутствии пути портал показывает пустое состояние без ошибки страницы.

## Постусловия

HTML и JSON содержат согласованный каталог, переходы и вычисленные связи.
Исходный Markdown не изменяется.
