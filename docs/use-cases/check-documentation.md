# UC-DOCS-02: Проверить документацию

Актор: разработчик или CI-процесс.

Разработчик или CI проверяет структуру и связи документации, не собирая портал
и не запуская команды рабочих задач.

## Входные данные

- каталог документации;
- корень репозитория;
- необязательный строгий режим `--strict`;
- ответ в формате `text` или `json`.

<!-- toudocu:section prerequisites -->
## Предусловия

- Toudocu доступен для запуска;
- инициатор может читать документацию и разрешённые файлы репозитория.

<!-- toudocu:section main-scenario -->
## Основной сценарий

1. Инициатор запускает `toudocu check ./docs`.
2. Toudocu читает Markdown и строит связанную модель проекта.
3. Утилита проверяет обязательный обзор архитектуры, вопросы остальных
   архитектурных документов, структуру, ID, ссылки, дорожную карту, стандарты,
   runbook, пользовательские разделы и рабочие задачи.
4. По умолчанию выводится понятный текст. С `--format json` возвращается
   `ProjectReport` версии 1.
5. Инициатор принимает результат по коду завершения и сообщениям отчёта.

## Ошибочные сценарии

- Недоступный каталог или неверный корень репозитория даёт код `1`.
- Ошибка структуры, ссылки или связи попадает в отчёт и всегда даёт код `1`.
- Без `--strict` предупреждения видны, но не меняют успешный код. С `--strict`
  любое предупреждение также даёт код `1`.
- `--stale-days 0` отключает только предупреждение о возрасте runbook. Неточная,
  отсутствующая или будущая дата проверки всё равно требует внимания.
- Ошибка чтения отдельного файла сохраняет его путь в сообщении.
- Отсутствующий или неверный `architecture/overview.md`, документ без
  архитектурного вопроса, непрямая карта или опасная ссылка считаются ошибкой.

<!-- toudocu:section postconditions -->
## Постусловия

Документы не изменены, портал не создан, команды из разделов «Проверка» не
запущены. Каждое сообщение имеет стабильный код и, когда возможно, путь, строку
и колонку.

<!-- toudocu:section acceptance-criteria -->
## Критерии приёмки

- [x] Проверка не меняет документы, не создаёт портал и не запускает команды из
  разделов «Проверка».
- [x] Каждое сообщение содержит стабильный код и, когда возможно, путь, строку
  и колонку.
- [x] Завершённый `UC-*` без полностью отмеченных критериев и несогласованная
  дорожная карта дают ошибку и код завершения `1` без изменения Markdown.
