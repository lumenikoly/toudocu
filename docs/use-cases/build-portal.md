# UC-DOCS-01: Создать автономный портал

- Идентификатор: UC-DOCS-01
- Статус: Готово
- Актор: Разработчик
- Модуль: MOD-SITE
- Приоритет: Высокий
- Последнее обновление: 2026-07-28

Разработчик преобразует каталог проектной документации в статический портал,
который можно открыть с диска без HTTP-сервера.

## Входные данные

- каталог проектной документации;
- выходной каталог;
- необязательные настройки repository URL, ref, excludes и stale threshold.

## Предусловия

- Docgent доступен для запуска;
- у разработчика есть права чтения исходного каталога и записи в выходной.

## Основной сценарий

1. Разработчик вызывает `docgent build ./docs --output ./build/project-docs`.
2. Docgent читает документы и проверяет структуру, ссылки и связанные сущности.
3. Docgent создаёт HTML-страницы, ресурсы поиска и `report.json`.
4. Docgent сообщает путь к созданному `index.html` и итоговую статистику.
5. Разработчик открывает `index.html` через `file://`.

## Ошибочные сценарии

- на шаге 2 недоступный исходный каталог завершает команду с кодом `1`, портал
  не создаётся;
- перед шагом 3 небезопасный путь `--output` или `--clean` отклоняется до
  удаления и записи файлов;
- если модель содержит ошибки, портал и `report.json` создаются с diagnostics,
  а команда завершается с кодом `1`;
- при `--strict` наличие предупреждений также приводит к коду `1`;
- ошибка записи или генерации прерывает сборку и выводится в stderr.

## Постусловия

При успешной генерации выходной каталог содержит автономный портал и
`ProjectReport` schema v1. Исходный Markdown не изменён.

## Проверка

- интеграционная генерация HTML и JSON;
- негативные тесты output, симлинков и активных assets;
- сборка минимального проекта только с `index.md`;
- открытие внутренних ссылок без HTTP-сервера.
