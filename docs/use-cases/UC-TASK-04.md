# UC-TASK-04: Архивировать или восстановить рабочую задачу

- Идентификатор: UC-TASK-04
- Статус: Готово
- Актор: Исполнитель — разработчик или программный агент
- Модуль: MOD-CLI
- Приоритет: Средний
- Последнее обновление: 2026-08-05

Исполнитель убирает завершённую или отменённую задачу из активного списка в
годовой архив либо возвращает архивный work item в активный каталог без
изменения его контракта.

## Входные данные

- стабильный `TASK-*` или `BUG-*` ID;
- каталог canonical documentation;
- repository root;
- формат результата `text` или `json`.

## Предусловия

- архивируемая задача имеет статус Done/Выполнено или Cancelled/Отменено;
- целевой путь не существует;
- прямые Markdown-ссылки сохраняют разрешение после перемещения.

## Основной сценарий

1. Исполнитель вызывает `docu-docu task archive TASK-ID ./docs`.
2. Docu-docu находит ровно один work item и проверяет его контракт, статус,
   исходный и целевой пути.
3. Docu-docu проверяет, что перемещение не разорвёт относительные Markdown-ссылки.
4. Файл без перезаписи перемещается в `work/archive/YYYY/`.
5. Команда возвращает `TaskMoveReport` со status `archived`.
6. При необходимости исполнитель вызывает `task restore` для того же ID.
7. Файл без изменения содержимого возвращается в `work/`, а отчёт получает
   status `restored`.

## Ошибочные сценарии

- отсутствующий или неоднозначный ID блокирует операцию;
- активная задача не архивируется;
- конфликт целевого пути не перезаписывается;
- небезопасный archive path, symlink или выход за repository root отклоняется;
- потенциально сломанная прямая Markdown-ссылка оставляет файл на месте;
- configured translation root отклоняется без перемещения work item.

## Постусловия

При успехе изменилось только расположение одного work item. Markdown, статус,
stable ID, зависимости и история задачи сохранены; при блокировке filesystem не
изменён.

## Проверка

- позитивные тесты archive и restore;
- блокировка активного статуса, конфликта назначения и небезопасного пути;
- сохранение содержимого и archive year в `TaskMoveReport`;
- блокировка прямых Markdown-ссылок, меняющих разрешение.
