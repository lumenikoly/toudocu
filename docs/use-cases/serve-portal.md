# UC-DOCS-03: Просматривать документацию на локальном сервере

- Идентификатор: UC-DOCS-03
- Статус: Готово
- Актор: Разработчик
- Модуль: MOD-SITE
- Приоритет: Средний
- Последнее обновление: 2026-07-28

Разработчик просматривает портал через локальный HTTP-сервер и получает
обновлённую сборку после изменения исходной документации.

## Входные данные

- каталог проектной документации;
- выходной каталог;
- адрес и порт сервера.

## Предусловия

- Docgent доступен для запуска;
- разработчик имеет права чтения документации и записи в выходной каталог.

## Основной сценарий

1. Разработчик вызывает `docgent serve ./docs`.
2. Docgent собирает портал в выходной каталог.
3. Docgent запускает HTTP-сервер на `127.0.0.1:8080` и сообщает адрес.
4. Разработчик открывает страницу портала в браузере.
5. При следующем запросе HTML-страницы Docgent пересобирает портал из актуальных
   Markdown-файлов.
6. Разработчик останавливает сервер сочетанием `Ctrl+C`.

## Ошибочные сценарии

- на шаге 2 ошибка чтения или генерации не оставляет работающий сервер;
- на шаге 3 занятый или недоступный порт завершает команду с кодом `1`;
- ошибка последующей пересборки возвращает HTTP 500 для текущего запроса, но не
  останавливает сервер;
- `--host 0.0.0.0` открывает сервер для локальной сети без TLS и авторизации;
  Docgent выводит явное предупреждение.

## Постусловия

Пока команда работает, HTTP-сервер раздаёт только выходной каталог. Исходный
Markdown и остальные файлы репозитория через HTTP недоступны. После остановки
процесса порт освобождён.

## Проверка

- первоначальная сборка и HTTP-раздача портала;
- пересборка при запросе HTML;
- HTTP 500 при ошибке пересборки без остановки процесса;
- недоступность исходных файлов репозитория;
- проверка loopback по умолчанию и сетевого предупреждения.
