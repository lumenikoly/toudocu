# Editor HTTP API: поведение и границы

[OpenAPI 3.1.0](editor.openapi.yaml) задаёт маршруты, параметры, коды ответа и
схемы JSON. Здесь описаны файловая граница редактора, безопасная запись,
пересборка портала и проверка новой версии — гарантии, которые не помещаются в
HTTP-схему.

В основном `serve` спецификацию можно открыть во встроенном Swagger UI.

## Где API доступен

Editor API существует только в основном `toudocu serve`. Его нет в статической
сборке, подключённых переводах и при прямом `serve` каталога перевода.

Go включает редактор только при возможности `editor` и передаёт его same-origin
адрес в JSON-блоке страницы. Браузер не выводит адрес из URL самостоятельно.

Редактор видит только разрешённые `.md`, `.yaml`, `.yml` и `.json` внутри
основного каталога документации. OpenAPI проверяется тем же анализатором, что и
при `toudocu check`.

## Проверка версии

Основной `serve` по умолчанию предоставляет адрес
`/_toudocu/api/version`. При первом запросе процесс один раз обращается к
фиксированному GitHub Releases API, принимает только стабильную версию `X.Y.Z`,
ждёт не более трёх секунд, читает не более 64 КиБ, запрещает перенаправления и
сохраняет результат до остановки.

Ссылка строится сервером для официальной страницы релиза; произвольный URL из
ответа GitHub не используется. Браузер обращается только к локальному адресу.
Более новая версия даёт ненавязчивое уведомление, которое можно скрыть для этой
версии. Ошибка или версия разработки возвращает `status: unavailable` и не
мешает порталу.

`--no-update-check` отключает возможность и адрес. Статический и переводной
порталы эту проверку не выполняют.

## Сохранение и создание файла

При открытии сервер возвращает SHA-256 содержимого. Сохранение принимается,
только если этот хеш всё ещё совпадает: так внешняя правка не теряется.
Временный файл создаётся в том же каталоге, наследует права, синхронизируется и
атомарно заменяет исходник. При конфликте браузер сохраняет введённый текст и
просит заново загрузить файл либо явно подтвердить перезапись с новым хешем.

Новый документ создаётся из общего реестра шаблонов и никогда не
перезаписывает существующий файл. Шаблон `draft` доступен только в Editor: он
создаёт свободный Markdown в `drafts/` с заголовком из обязательного поля
`title`. Имя файла — безопасный slug заголовка; при совпадении Editor добавляет
последовательный суффикс. Команда `scaffold` этот шаблон не принимает.
Диагностические сообщения видны пользователю, но сами по себе не запрещают
сохранение.

## Добавление результата в дорожную карту

Запрос чтения возвращает текущие хеш и версию, существующие этапы H2 и следующий
предложенный `DLV-ROADMAP-NNN`. Запись принимает только новый незавершённый
`DLV-*` для существующего этапа. ID приводится к верхнему регистру и должен быть
уникальным; текст — одна непустая строка без второго ID.

Используются та же защита пути, сверка хеша и атомарная замена. Новый пункт
вставляется после последнего пункта этапа, а если их нет — перед следующим H2.
Переводы строк и остальной Markdown не форматируются заново.

При `stale_digest` автоматической перезаписи нет. Ответ содержит свежие этапы,
хеш и новый предложенный ID, чтобы браузер сохранил поля формы и попросил
повторное осознанное подтверждение.

## Граница доверия

Записывающий запрос требует JSON, правильного заголовка действия и same-origin
контекста браузера. Это защищает локальный браузерный путь, но не является
аутентификацией. Сервер на `0.0.0.0` доступен другим клиентам локальной сети.

Допустим только относительный POSIX-путь внутри основного каталога. Пустой и
абсолютный путь, `.`, `..`, обратная косая черта, NUL, скрытые, исключённые и
выходные каталоги и любой компонент-символическая ссылка отклоняются. Editor
API не запускает Git, системную оболочку и команды задач.

## Пересборка

После принятого сохранения, создания или добавления `DLV-*` сервер сразу
перестраивает модель, HTML, поиск и диагностические сообщения. Ошибка
пересборки возвращается текущему запросу, но не останавливает HTTP-сервер.
Ручная пересборка использует тот же OpenAPI-контракт, читает основной каталог и
не меняет Markdown.

Все технические `message` в ответах Editor, пересборки и проверки версии
возвращаются на английском независимо от локали интерфейса. Стабильный `code`
остаётся машинным контрактом; пользовательские пути и другие входные значения
в сообщении не переводятся.
