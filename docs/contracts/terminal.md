# Терминал проекта

В `serve` на loopback-адресе кнопка «Терминал проекта» открывает боковую панель.
Оболочка запускается только после отдельного действия «Запустить терминал».
Закрытие панели и переходы между страницами не останавливают процесс; его
завершают кнопка остановки или закрытие сервера. Открытие обсуждений скрывает
панель терминала, сохраняя процесс. Статическая сборка и non-loopback `serve`
не предоставляют эту возможность.

## Запуск и границы доступа

Сервер создаёт PTY в корне репозитория и выбирает обычную оболочку платформы
из своего окружения. Браузер не задаёт executable, argv, cwd или environment.
Ввод, прерывание и изменение размера доступны только существующему терминалу.
Toudocu не разбирает его вывод и не управляет запущенным в нём coding agent.

HTTP и WebSocket проверяют loopback `Host`, адрес соединения и same-origin
контекст. POST дополнительно требует известный `X-Toudocu-Action` и пустое
JSON-тело; неизвестные поля отклоняются. Точные пути и HTTP-схемы находятся в
[Terminal OpenAPI](terminal.openapi.yaml).

## Поток терминала

WebSocket передаёт сообщения с `sequence` для восстановления потока: состояние терминала,
вывод или завершение и уведомление `replay_gap` об истёкшем буфере. Его номер совпадает с первым
повторяемым событием; остальные сообщения получают возрастающий номер. Вывод
передаётся в base64. Параметр `since` запрашивает пропущенные события; сервер
хранит ограниченный буфер и закрывает слишком медленное соединение. Клиент
повторяет подключение; закрытие WebSocket само по себе не останавливает PTY.

Входные сообщения имеют действия `terminal-input` (текст до 65 536 символов),
`terminal-resize` (целые размеры 2–500) или `terminal-interrupt`. Неизвестные
действия и некорректные поля отклоняются с закрытием WebSocket. Схемы находятся
в `packages/contracts/src/terminal.ts`.

## Удалённая интеграция

Agent Console, её провайдеры, история сессий, управление разрешениями и
проверка задач из панели удалены. Пути `/_toudocu/api/agent-console/*` больше
не обслуживаются. Capability `agentConsole` удалена из снимка портала;
`terminal` определяет доступность терминала. Обсуждения и CLI `agent next` /
`agent respond` работают независимо от терминала. Проверки задач доступны
через явную команду CLI; кнопки задачи копируют инструкцию и контекст.
