# Контракт действий задачи

Портал показывает действия по вычисленному состоянию задачи и копирует
короткие инструкции для внешнего агента. Архивные и отменённые задачи не
показывают меню действий. Копирование работает в статическом и локальном
портале, не запускает процесс и не меняет статус задачи.

## Копирование

Доступные инструкции включают начало или продолжение работы, уточнение,
объяснение блокера, исправление проблем, запрос следующего шага и выполнение
дерева задач. Текст содержит ID задачи; внешний агент получает актуальную
модель через навык Toudocu. Портал показывает подтверждение копирования, а при
отказе Clipboard API — сообщение об ошибке. Встроенной доставки в Agent
Console, сессий и серверной цели дерева больше нет.

Кнопка «Копировать контекст» в заголовке документа сохраняет название и путь
исходного документа. Она остаётся доступной и на странице задачи.

## Прямое завершение

В `serve` при доступных taskActions и editing кнопка завершения показывается
по `workspace.canComplete`. После подтверждения портал читает актуальный файл,
заменяет `in-progress` на `done`, отправляет текст на валидацию и сохраняет его
через [Editor API](editor-http.md) с полученным digest. Ошибки проверки или
конфликт сохранения показываются пользователю. Успех перезагружает страницу.
Эта операция не запускает команды проверки и не обновляет дату автоматически.

Копирование «Начать работу» само по себе не переводит задачу в `in-progress`.
Отдельного Task Actions HTTP API с подготовкой и доставкой действий нет;
публичные операции чтения и проверки задач остаются в [CLI](cli.md).
