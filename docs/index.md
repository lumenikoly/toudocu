# Toudocu

Toudocu — dependency-free CLI на Go с публичным Go-фасадом для проверяемой
проектной документации в структурированном Markdown и backend-independent
HTML-портала для обычного HTTP(S) static hosting.

## Проблема

Проектная документация быстро расходится с кодом, когда статусы, связи,
критерии приёмки и команды проверки хранятся в несогласованных файлах или
требуют ручной синхронизации.

## Решение

Toudocu строит единую модель из Markdown, проверяет стабильные идентификаторы,
ссылки, бизнес-правила, roadmap и work items, а затем отдаёт результат человеку
в HTML и автоматизации в JSON ProjectReport schema v1.

## Основные возможности

Toudocu превращает Markdown рядом с кодом в связанную и проверяемую систему
документации.

- **Единый портал проекта.** Поиск, навигация, архитектурная карта,
  пользовательские сценарии и текущее состояние работы собраны в одном
  понятном интерфейсе.
- **Проверяемая документная модель.** Валидация контролирует ссылки, стабильные
  идентификаторы, структуру документов и явно объявленные связи между ними.
- **Сквозная трассируемость.** Пользовательский сценарий и экран связаны с
  задачей, критерием приёмки и командой, подтверждающей результат.
- **Смысловой review изменений.** Git-backed workspace показывает исходный,
  отрисованный и семантический diff документации до публикации.
- **Контекст задачи для AI-агента.** Компактный read-only пакет включает только
  связанные требования, правила, экраны, зависимости и проверки выбранной
  задачи.
- **Встроенный AI-skill для документации.** Offline-пакет подключает Toudocu к
  Codex, Claude Code и Copilot и добавляет явные workflow для инициализации,
  полной или diff-актуализации и перевода документации. CLI устанавливает,
  проверяет, обновляет и удаляет managed-копию без сети и не перезаписывает
  пользовательские изменения. Начните с
  [руководства по установке](guides/skill-installation.md), затем используйте
  [руководство по agent-workflows](guides/agent-workflows.md) для обычных
  CLI-, portal-, task- и documentation-сценариев.
- **Проверяемые рабочие задачи.** Work item объединяет scope, критерии приёмки
  и команды проверки; Toudocu проверяет его готовность, выполняет явно
  разрешённые команды и сохраняет результат.
- **Автономная публикация.** Один Go-бинарник создаёт статический портал без
  CDN, базы данных, npm и внешнего runtime — для локального просмотра или
  обычного static hosting.

## Целевая аудитория

- разработчики и технические руководители;
- команды, ведущие документацию рядом с кодом;
- LLM-агенты, которым нужен ограниченный и машиночитаемый контекст;
- CI-системы, проверяющие документационный контракт;
- Go-разработчики, встраивающие Toudocu из исходного модуля.

## Ограничения

- dialect ограничен CommonMark и явно включёнными tables, task lists,
  strikethrough и literal autolinks;
- команды `task verify --run` считаются доверенным кодом репозитория;
- результат `build` является статическим и не редактирует исходные документы;
- режим `serve` изменяет только явно выбранные canonical workspace-файлы через
  editor API и не предоставляет запись в translation roots;
- глобальный прогресс определяется только `roadmap.md`.
