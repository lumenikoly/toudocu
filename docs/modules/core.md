# Основной модуль

- Идентификатор: MOD-CORE
- Статус: В работе
- Владелец: Команда проекта
- Последнее обновление: 2026-07-26

Основной модуль демонстрирует рекомендуемую структуру описания кода и правил.

## Назначение

Реализует основной пользовательский результат проекта.

## Расположение в коде

- Исходный код: `src/core/`
- Тесты: `test/core/`

## Границы

Модуль отвечает за основной сценарий, но не за внешние интеграции.

## Бизнес-правила

### BR-CORE-001: Результат создаётся только после проверки входных данных

Некорректные входные данные не изменяют состояние системы.

## Инварианты

- Состояние остаётся согласованным после любой ошибки.
