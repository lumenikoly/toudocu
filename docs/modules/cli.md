# CLI и процессы задач

Модуль объединяет проверку, сборку, локальный сервер, поиск, изменения,
обратную связь и work-item workflow. Коды завершения стабильны, машинные
ответы используют `schemaVersion: 1`.

<!-- toudocu:section code-location -->
## Расположение в коде

- `apps/cli/src/` — разбор команд, вывод и коды завершения;
- `packages/application/src/` — прикладные сценарии;
- `packages/core/src/tasks/` — модель задач без I/O;
- `packages/platform-node/src/` — filesystem, Git, process, skill и PTY;
- `packages/server/src/` — `serve`, HTTP/WebSocket и watcher.

<!-- toudocu:section boundaries -->
## Границы

CLI не интерпретирует естественный язык. `$toudocu init`, `refresh`,
`translate` и `clarify` выполняет AI-агент; одноимённых верхнеуровневых команд
нет. Поддерживаемые интерфейсы интеграции — CLI и JSON, публичный SDK не
обещается.

`task ready`, `candidates`, `tree`, `changes` и `context` только читают.
Команды проекта запускает исключительно явный `task verify --run`. Skill
размещает готовые файлы и не исполняет их содержимое.

<!-- toudocu:section business-rules -->
## Бизнес-правила

### BR-CLI-001: Контекст задачи не исполняет команды

`task context` возвращает требования, связи и диагностику без shell.

### BR-CLI-002: Проверки запускаются только явно

Проверки `AC-*`, `ALL`, `DOCS` и `QUALITY` выполняются только по явному
разрешению; одинаковая команда запускается один раз.

### BR-CLI-003: Превышение времени завершает дерево процессов

Timeout и отмена завершают всё дерево дочернего процесса.

### BR-CLI-004: Toudocu не интерпретирует пользовательский запрос

Каркас и проверки остаются нейтральными; связи, требования и статус задаёт
исполнитель.

### BR-CLI-005: Браузер и CLI используют один реестр каркасов

Task/scaffold registry определяет путь и шаблон; файл создаётся атомарно без
перезаписи.

### BR-CLI-006: Выбранная локаль является рабочим контекстом

Locale root является самостоятельным рабочим контекстом и не
синхронизируется автоматически.

### BR-CLI-007: Архивирование не изменяет контракт задачи

Archive/restore перемещает один work item без изменения Markdown.

### BR-CLI-008: Управляемый skill не перезаписывает изменения пользователя

Управляемая копия не перезаписывается, если она изменена, неизвестна или новее
встроенной версии.

### BR-CLI-009: Жизненный цикл skill работает без сети

Установка, проверка, обновление и удаление встроенного skill не требуют сети.

### BR-CLI-010: Все назначения планируются до записи

Множественная skill-операция сначала проверяет все уникальные назначения.

### BR-CLI-011: Дерево не расширяет границу выполнения

`verify` запускает только команды выбранной задачи, а не её дочерних элементов.

<!-- toudocu:section invariants -->
## Инварианты

- JSON не смешивается с потоковым текстом.
- Команды задачи запускаются из repository root, последовательно и с
  ограниченным stdout/stderr.
- Путь без команды не начинает скрытую сборку.
- `serve` по умолчанию слушает loopback и не открывает браузер без `--open`.
- CLI-generated текст английский; содержимое Markdown не переводится.
- Изменяющая skill-операция повторно проверяет назначение перед публикацией.

<!-- toudocu:section stable-interfaces -->
## Стабильные интерфейсы

- команды и параметры [CLI-контракта](../contracts/cli.md);
- версионируемые `ProjectReport`, task reports, `SearchReport`,
  `ChangeSetReport` и skill results;
- код `0` только для успешного результата или допустимого отсутствия изменения.
