# Изоляция ошибок документации и проверок

Проблемы чтения и структуры превращаются в сообщения, привязанные к файлам, и
никогда сами по себе не приводят к запуску кода. Команды задачи выполняются
только после явного разрешения, каждая в отдельном процессе. Редактор `serve`
может изменить лишь выбранный разрешённый файл, а команда проверки работает с
правами текущего пользователя и поэтому потенциально может изменить весь
репозиторий.

## Область

Здесь разделены ошибки документации, запущенных команд и редактора.
Пользовательские последовательности описаны в
[FLOW-DOCS-CHECK](../flows/FLOW-DOCS-CHECK.md) и
[FLOW-TASK-WORKFLOW](../flows/FLOW-TASK-WORKFLOW.md).

## Ошибки документации

Сканирование продолжает читать доступные документы, а найденные проблемы
добавляются к общей модели и конкретным файлам. Ошибка делает операцию
неуспешной; предупреждение меняет код завершения только с `--strict`. Ни один
путь диагностики не выполняет команды из рабочей задачи.

## Ошибки команд задачи

`task verify --run` сначала проверяет, что локальный контракт задачи полный и
корректный. Затем каждая уникальная команда запускается из корня репозитория.
Сбой одной команды не скрывает результаты остальных. Превышение времени
останавливает всё дерево её процессов, а stdout и stderr сохраняются только в
ограниченном объёме. Отчёт о выполнении не записывается обратно в исходный
Markdown.

Toudocu не может гарантировать безопасность побочных эффектов самой команды.
Эту ответственность принимает пользователь, когда явно разрешает запуск в
доверенном репозитории.

## Ошибки редактора

Сообщения предварительного просмотра не мешают сохранить файл. Неверный запрос,
опасный путь, слишком большое содержимое или устаревший хеш отклоняются до
замены исходника. Временный файл создаётся в том же каталоге, синхронизируется и
атомарно заменяет исходник только после повторной сверки хеша. Ошибка последующей
сборки возвращается текущему запросу или попадает в журнал наблюдателя, но не
запускает команду проекта и не останавливает уже работающий сервер.
