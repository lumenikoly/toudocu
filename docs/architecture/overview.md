# Архитектура

- Тип документа: Architecture Overview

Docgent — локальный dependency-free Go CLI между исходным каталогом документации
и двумя потребителями проверенной модели: автоматизацией через CLI/JSON и
читателем автономного HTML-портала. Опциональный `serve` добавляет локальный
HTTP/editor runtime; база данных и внешний runtime в границу системы не входят.

## Граница системы

Разработчик, агент или CI передаёт Docgent каталог документации и явно
выбранный repository root. Docgent читает Markdown и локальные assets,
проверяет объявленные связи и либо возвращает diagnostics, либо строит
производные HTML/JSON-файлы. В `build` браузер только открывает готовый read-only
портал. В `serve` он может отправить ограниченную workspace-запись, после которой
Go-процесс снова строит модель. Только отдельный явный режим проверки задачи
может запускать команды репозитория.
