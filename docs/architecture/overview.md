# Архитектура Docgent

- Тип документа: Architecture Overview

Docgent — локальный dependency-free Go CLI между исходным каталогом Markdown
и двумя потребителями проверенной модели: автоматизацией через CLI/JSON и
читателем автономного HTML-портала. Сеть, база данных и внешний runtime в
границу системы не входят.

## Граница системы

Разработчик, агент или CI передаёт Docgent каталог документации и явно
выбранный repository root. Docgent читает Markdown и локальные assets,
проверяет объявленные связи и либо возвращает diagnostics, либо строит
производные HTML/JSON-файлы. Браузер открывает готовый портал, но не участвует
в построении проектной модели. Только отдельный явный режим проверки задачи
может запускать команды репозитория.
