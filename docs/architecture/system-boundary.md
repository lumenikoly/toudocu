# Системная граница Toudocu

Toudocu — локальный Node.js CLI. Он читает Markdown и разрешённые данные
репозитория, строит модель и возвращает диагностику, JSON или готовый портал.
Поддерживаемый программный интерфейс автоматизации — CLI и его версионируемые
JSON-ответы; публичного JavaScript SDK нет.

В режиме `serve` тот же процесс предоставляет loopback HTTP/WebSocket API для
редактора, Changes, Discussions, Agent Console и Project Terminal. Состояние
обсуждений хранится в пользовательском каталоге, а не в репозитории. Сервер
может один раз проверить метаданные стабильного выпуска GitHub; флаг
`--no-update-check` полностью отключает этот запрос.

## Кто взаимодействует с Toudocu

- разработчик, агент или CI выбирает команду, documentation root и repository root;
- файловая система предоставляет Markdown, конфигурацию и локальные ресурсы;
- Git предоставляет только локальные коммиты, индекс и рабочее дерево;
- браузер читает статический портал или same-origin API локального `serve`;
- Codex/OpenCode и системная оболочка запускаются только по явному действию в
  основном loopback `serve`;
- команды skill изменяют только явно выбранный каталог проекта или пользователя.

Статический портал остаётся обычным HTTP-артефактом и не требует Node.js на
хостинге. Toudocu не использует базу данных, не меняет Git и не запускает
команды из рабочей задачи без явного `task verify --run`.

Точные команды описывает [CLI-контракт](../contracts/cli.md), а установка —
[руководство](../guides/installation.md).
