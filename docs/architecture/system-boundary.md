# Системная граница Docgent

- Тип документа: Architecture
- Архитектурный вопрос: Где проходит системная граница Docgent и кто с ней взаимодействует?

Docgent ограничен одним локальным процессом, который читает документацию и
репозиторий, строит проверенную модель и выдаёт diagnostics либо производные
представления. Пользователь, агент, CI и браузер остаются взаимодействующими
сторонами за этой границей.

## Область

Ответ описывает только границу CLI как исполняемой системы и её внешние
взаимодействия. Команды, форматы и причины dependency-free поставки остаются в
[CLI-контракте](../contracts/cli.md) и
[ADR-001](../decisions/001-dependency-free.md).

## Взаимодействующие стороны

- разработчик или агент выбирает вход, repository root и операцию;
- CI использует exit code и `ProjectReport` schema v1;
- файловая система предоставляет Markdown, локальные assets и разрешённые
  repository targets;
- браузер читает автономный портал через `file://` или локальный HTTP;
- shell и дочерние процессы доступны только явному `task verify --run`.

## Что остаётся снаружи

Docgent не хранит серверное состояние, не обращается к базе данных и не
интерпретирует пользовательский запрос. Граница между детерминированным CLI и
смысловой работой исполнителя зафиксирована в
[ADR-002](../decisions/ADR-002.md).
