## RISK-01: Изменение правил разбора Markdown
Goldmark одинаково разбирает CommonMark/GFM во всех командах Toudocu. Однако
обновление его версии или включённых расширений может изменить HTML, границы
фрагментов исходного текста и результат нормализации. Это способно повлиять на
портал, ссылки и привязку комментариев к строкам.

### Как снижается риск

- [x] Поддерживаемые конструкции описаны в README и справочнике возможностей.
- [x] Отрисовка и безопасное экранирование покрыты поведенческими тестами.
- [x] Документы проекта включены в набор примеров для проверки Goldmark.
- [x] Версию Goldmark или набор расширений нужно обновлять вместе с проверкой
  всего набора документов, безопасности и смысла получившихся страниц.

## RISK-02: Выполнение команд из рабочей задачи
Команды из раздела проверки рабочей задачи запускаются системной оболочкой и
получают те же права, что и пользователь Toudocu. Поэтому задача из
недоверенного источника может содержать опасную команду.

### Как снижается риск

- [x] `check`, `build` и `task context` никогда не выполняют эти команды.
- [x] Для запуска требуется явная команда `task verify --run`.
- [x] Время выполнения и объём сохранённого вывода ограничены.

Перед `task verify --run` пользователь всё равно должен прочитать команды и
убедиться, что доверяет их источнику.

## RISK-03: Потеря данных при очистке выходного каталога
Ошибка в обработке `build --clean` могла бы удалить данные за пределами
каталога портала.

### Как снижается риск

- [x] Нельзя очищать корень файловой системы, каталог документации и его
  родительские каталоги.
- [x] Перед очисткой раскрываются и проверяются символические ссылки.
- [x] Для каждого исправленного опасного случая сохраняется отдельный
  негативный тест.
