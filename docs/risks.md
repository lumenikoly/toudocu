# Риски

Актуальные технические и эксплуатационные риски Toudocu.

## RISK-01: Изменение Markdown dialect или движка

- Статус: Снижается
- Вероятность: Низкая
- Влияние: Среднее
- Владелец: Команда Toudocu

Goldmark даёт единый CommonMark/GFM AST, но обновление версии или набора
расширений способно изменить нормализацию, source ranges и canonical HTML.

### План снижения риска

- [x] Зафиксировать поддерживаемые конструкции в README и справочнике
  возможностей.
- [x] Покрыть рендеринг и экранирование поведенческими тестами.
- [x] Перевести текущие документы в regression corpus Goldmark cutover.
- [ ] Обновлять dialect или engine только вместе с corpus, security и semantic review.

## RISK-02: Выполнение доверенных команд задачи

- Статус: Риск принят
- Вероятность: Низкая
- Влияние: Высокое
- Владелец: Пользователь репозитория

Команды в разделе проверки work item исполняются через системную оболочку и
имеют права запустившего Toudocu пользователя.

### План снижения риска

- [x] Никогда не выполнять команды при `check`, `build` или `task context`.
- [x] Требовать явный вызов `task verify --run`.
- [x] Ограничивать время и объём сохранённого вывода команды.

## RISK-03: Ошибка при очистке output

- Статус: Снижается
- Вероятность: Низкая
- Влияние: Высокое
- Владелец: Команда Toudocu

Ошибочная реализация `--clean` способна повредить данные вне каталога
генерации.

### План снижения риска

- [x] Запретить корень, каталог документации и его родительские каталоги.
- [x] Проверять раскрытые пути и символические ссылки.
- [x] Сохранять негативные тесты для каждого исправленного сценария.
