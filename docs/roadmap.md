# Дорожная карта

Roadmap определяет продуктовый охват Docgent; состояние связанных `UC-*`
вычисляется из документов пользовательских сценариев.

## Реализовано

- Статус: Готово
- Владелец: Команда Docgent

- [x] `UC-DOCS-01` Пользователь создаёт автономный портал документации.
- [x] `UC-DOCS-02` Пользователь проверяет структуру и связи документации.
- [x] `UC-DOCS-03` Пользователь просматривает документацию на локальном сервере.
- [x] `UC-DOCS-04` Пользователь исследует карту экранов и переходы.
- [x] `UC-TASK-01` Исполнитель получает контекст выбранной задачи.
- [x] `UC-TASK-02` Исполнитель запускает проверки выбранной задачи.
- [x] `UC-TASK-03` Исполнитель подготавливает новую рабочую задачу.
- [x] `CON-CLI-V1` Зафиксирован публичный CLI-контракт и versioned JSON schemas.
- [x] `DLV-SELF-DOCS-01` Репозиторий содержит собственную проверяемую документацию.
