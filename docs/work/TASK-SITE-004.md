## Результат

На странице `roadmap.md` в каноническом `toudocu serve` пользователь может
добавить незавершённый `DLV-*` в существующий этап через диалог, не редактируя
Markdown вручную. Статический портал и переводы остаются доступны только для
чтения.

## Изменение поведения

### Было

Дорожная карта показывала прогресс, но новый результат можно было добавить
только в общем редакторе или внешней программой.

### Станет

Действие, доступное только в `serve`, получает актуальные этапы, хеш файла и
предложенный `DLV-ROADMAP-NNN`. Сервер проверяет однострочный текст, атомарно
вставляет незавершённый пункт в выбранный раздел H2 и пересобирает портал. При
конфликте файл не перезаписывается, а введённые значения остаются в форме.

## Область изменения

- API дорожной карты, безопасная вставка и проверка хеша в `internal/app/`;
- диалог, его повторная инициализация и браузерные тесты в `web/`;
- сгенерированные ресурсы `serve`;
- связанные контракты, процессы, руководства, модули, экраны, сценарии и
  дорожная карта.

## Не входит в задачу

- создание этапов, `UC-*`, `CON-*` или автоматическое создание `TASK-*`;
- редактирование, завершение и удаление существующих пунктов;
- изменение `ProjectReport`, схемы блока запуска или публичного Go API;
- запись из статического портала и переводов.

## Критерии приёмки

- [x] `AC-01` `GET` возвращает номер версии, путь, хеш, предложенный следующий
  `DLV-ROADMAP-NNN` и существующие этапы с якорем, названием, статусом и числом
  пунктов. Отсутствующая дорожная карта даёт стабильную ошибку.
- [x] `AC-02` `POST` принимает только JSON с того же origin и действие
  `roadmap-add`. Сервер отклоняет неизвестные поля, пустой или многострочный
  текст, второй идентификатор, дубликат, неизвестный этап и устаревший хеш.
- [x] `AC-03` Запись сохраняет переносы строк и окружающий Markdown, вставляет
  пункт в правильное место, атомарно заменяет файл и сразу перестраивает
  портал.
- [x] `AC-04` Диалог поддерживает клавиатуру, `Escape`, управление фокусом,
  состояния загрузки/ошибки/успеха и узкий экран. При конфликте поля
  сохраняются, а этапы, хеш и подсказка обновляются.
- [x] `AC-05` Статический портал и переводы не содержат кнопку, адрес API и код
  записи. Общий редактор и публичные схемы не меняются.
- [x] `AC-06` Связанные контракты и пользовательские документы согласованы с
  поведением.
