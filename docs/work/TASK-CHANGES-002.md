## Результат

После выполнения задачи раздел «Изменения» стал сразу открывать первый
подходящий diff. В основном интерфейсе остались список файлов, поиск, статус и
обсуждения; параметры Git и диагностические сообщения открывались по запросу.

## Изменение поведения

### Было

До выбора файла большую часть экрана занимали параметры Git, метрики и
дополнительные фильтры, а diff был скрыт за вкладкой «Сводка».

### Станет

Первый подходящий файл и его diff открываются автоматически. Диапазон Git и
диагностические сообщения находятся в компактных раскрывающихся блоках. На
компьютере, планшете и телефоне прокручиваются отдельные панели, а не вся
страница по горизонтали.

## Область изменения

- `internal/site/` — HTML рабочей области и тесты шаблонов;
- `web/src/` и `web/tests/` — интерфейс, адаптивная раскладка и браузерные
  тесты;
- `internal/site/assets/generated/` — результат сборки из `web/`;
- `docs/screens/SC-CHANGES-WORKSPACE.md`, эта задача и `CHANGELOG.md`.

## Не входит в задачу

- Go-фасад, `ChangeSetReport`, структуры данных обсуждений, HTTP API и передача
  комментариев агенту;
- полный визуальный пересмотр Toudocu и изменение `DESIGN.md`;
- возможности статического портала и переводов.

## Критерии приёмки

- [x] `AC-01` Шапка объединяет название, раскрывающийся диапазон Git, сводку по
  файлам и обсуждения. Диапазон закрывается после применения, по `Esc` и по
  клику снаружи; фокус возвращается к кнопке.
- [x] `AC-02` Панель файлов содержит только поиск и статус, сортирует по пути и
  делит файлы на «Изменённые» и «Связанные», не повторяя имя файла.
- [x] `AC-03` Первый подходящий файл открывается автоматически. URL, обновление
  наблюдателем и фильтры сохраняют согласованный выбор файла и вкладки.
- [x] `AC-04` Вкладка «Сводка» удалена. Диагностический блок виден только при
  наличии сообщений и сам раскрывается при ошибке.
- [x] `AC-05` Остальные представления документации, переключатель вида diff,
  копирование, комментарии к файлу или диапазону, обсуждения и передача
  комментариев сохраняют поведение.
- [x] `AC-06` На большом экране используется разделённая рабочая область; на
  планшете и телефоне боковые панели не создают горизонтальную прокрутку и
  поддерживают фокус и `Esc`.
- [x] `AC-07` Каноническая документация и сгенерированные браузерные ресурсы
  согласованы с реализацией.
