# TASK-SITE-001: Добавить копирование контекста документа

<!-- toudocu:section result -->
## Результат

На странице исходного Markdown-документа пользователь может одним действием
скопировать его название и путь относительно репозитория, чтобы точно указать
AI-агенту нужный источник.

<!-- toudocu:section behavior-change -->
## Изменение поведения

<!-- toudocu:section before -->
### Было

Портал позволял копировать код, но не давал короткого контекста открытого
документа.

<!-- toudocu:section after -->
### Станет

Обычная страница документа, страница пользовательского сценария и главная
страница `index.md` получают кнопку «Копировать контекст». В буфер записываются
две строки:

```text
Документ: <название>
Путь: <путь от корня репозитория>
```

<!-- toudocu:section scope -->
## Область изменения

- генерация страниц и браузерная логика портала;
- стили и тесты копирования;
- описание модуля и справочник возможностей.

<!-- toudocu:section out-of-scope -->
## Не входит в задачу

- копирование полного текста документа;
- кнопка в каталогах, карте экранов, трассировке и на странице состояния;
- изменение CLI, Go API или `report.json` schema v1;
- новые зависимости.

<!-- toudocu:section acceptance-criteria -->
## Критерии приёмки

- [x] `AC-01` Обычный документ, сценарий и главная страница копируют название
  и относительный путь в согласованном двухстрочном формате.
- [x] `AC-02` Каталоги и служебные страницы не получают эту кнопку.
- [x] `AC-03` Сначала используется Clipboard API, а в браузерах без него —
  встроенный запасной способ. Результат озвучивается и действие доступно с
  клавиатуры.
- [x] `AC-04` Абсолютный путь не раскрывается; если документ находится вне
  корня репозитория, используется безопасный `SourcePath`.
