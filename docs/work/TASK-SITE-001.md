# TASK-SITE-001: Добавить копирование контекста документа

- Статус: Выполнено
- Тип: Feature
- Приоритет: Средний
- Модуль: MOD-SITE
- Сценарий: UC-DOCS-01
- Владелец: Команда Docgent
- Последнее обновление: 2026-07-30

## Результат

На страницах исходных Markdown-документов пользователь может одним действием
скопировать название и repository-relative путь, чтобы передать точный контекст
агенту.

## Изменение поведения

### Было

Портал позволял копировать блоки кода, но не предоставлял короткую ссылку на
исходный документ открытой страницы.

### Станет

Обычные страницы документов, канонические страницы use case и главный dashboard
для `index.md` содержат кнопку «Копировать контекст». В буфер записываются две
строки:

```text
Документ: <название>
Путь: <путь от repository-root>
```

## Область изменения

- `internal/app/site.go`;
- `internal/app/process_site.go`;
- `internal/app/assets/app.js`;
- `internal/app/assets/style.css`;
- тесты генерации портала в `internal/app/`;
- исходная документация модуля и каталога возможностей.

## Не входит в задачу

- копирование полного содержимого документа;
- кнопка на каталогах, Screen Map, traceability и health page;
- изменение CLI, Go API или `report.json` schema v1;
- новые зависимости.

## Критерии приёмки

- [x] `AC-01` Обычный документ, use case и dashboard копируют название и
  repository-relative путь в согласованном двухстрочном формате.
- [x] `AC-02` Каталоги и служебные страницы не получают кнопку контекста.
