# SC-CHANGES-WORKSPACE: Изменения

- Идентификатор: SC-CHANGES-WORKSPACE
- Тип: Экран
- Модуль: MOD-CHANGES
- Статус: Реализован
- Маршрут: `/changes/`
- Последнее обновление: 2026-08-10

Экран помогает проверить текущий Git diff и обсудить его с агентом, не покидая
локальный портал. Он показывает не только документацию, но и остальные
изменённые или вручную связанные файлы репозитория. Публичный JSON-отчёт
`ChangeSetReport` по-прежнему ограничен документацией.

Актуальный снимок экрана пока не подготовлен. Файл
`assets/screens/changes-workspace.png` показывает прежнюю компоновку и поэтому
не указан как превью этого документа.

## Что видит пользователь

В верхней панели находятся переходы в портал, редактор и раздел «Изменения», а
также выбор темы и цветовой схемы. Ниже показаны диапазон Git, число изменённых
файлов и строк и кнопка «Обсуждения».

Параметры диапазона скрыты под раскрывающейся строкой. Там можно задать
начальное и конечное состояния и, при необходимости, базовую ветку. Рядом
показано, во что разрешились ссылки Git, какая ветка открыта и есть ли локальные
правки. Панель закрывается после применения, по `Esc` или клику снаружи и
возвращает фокус на строку диапазона.

## Список файлов

Файлы отсортированы по пути и разделены на две группы:

- «Изменённые» — файлы из текущего Git diff;
- «Связанные» — файлы, которые пользователь добавил для контекста обсуждения.

В панели есть поиск, отбор по состоянию и области, а также фильтр «Тип»: все
файлы, только документация вместе с корневым `CHANGELOG.md` или только остальные
файлы репозитория. Связанный файл сохраняется в локальном состоянии только после
первого комментария.

Первый подходящий файл открывается автоматически. После обновления страницы
Toudocu старается сохранить выбранные файл, вкладку и фильтры. Если ничего не
подходит, экран честно сообщает, что список пуст.

## Просмотр файла

Основная вкладка называется «Diff» и показывает точный патч Git. Внутри неё
можно выбрать единый вид или две стороны и скопировать патч. Отдельной вкладки
«Сводка» нет; старые ссылки с `tab=summary` и `tab=source` перенаправляются на
«Diff».

Вкладка «Файл целиком» загружает текущий UTF-8 файл только при открытии. Для
удалённого файла показывается последняя версия до удаления. Markdown, JSON,
YAML, Go, Java, JavaScript и TypeScript получают подсветку; остальные текстовые
файлы отображаются как обычный текст.

Для документации появляются только применимые вкладки: «До и после»,
«Семантика», «Связи», OpenAPI, Mermaid, ресурсы или карта экранов. Диагностические
сообщения скрыты, пока они не нужны; сообщение уровня `error` раскрывается
автоматически.

## Комментарии и ответы агента

Комментарий можно оставить для всего набора, целого файла, строки патча или
выделенного фрагмента во вкладке «Файл целиком». Форма содержит одно поле —
текст сообщения. `Ctrl`+`Enter` или `Cmd`+`Enter` сохраняет его, `Esc` отменяет
ввод. Диапазон, одновременно затрагивающий старую и новую стороны патча, не
принимается.

Панель обсуждений скрыта, пока сообщений нет. После первого сообщения она
показывает открытые и закрытые обсуждения. Неотправленное сообщение можно
изменить или удалить. После подготовки пакета для агента оно становится
неизменяемым; продолжение создаётся отдельным ответом.

Кнопка «Отправить агенту» не запускает агента. Она создаёт ожидающий пакет и
показывает фразу, которую пользователь передаёт агенту. Результат агента
отображается словами «Исправлено», «Не исправлено» или «Нужно уточнение» и не
закрывает обсуждение автоматически.

## Обновление и размеры экрана

Toudocu отдельно следит за изменениями репозитория и обсуждений. Если открытый
файл изменился, появляется предложение обновить его. Текст незавершённого
комментария сохраняется, но место нужно выбрать снова.

На широком экране список файлов, diff и открытые обсуждения расположены рядом.
На планшете обсуждения открываются справа, на телефоне список файлов и
обсуждения становятся отдельными выдвижными панелями. Их можно закрыть по
`Esc`; состояния и результаты выражены текстом, а не только цветом.

## Где экран доступен

Раздел и запись комментариев доступны только в основном портале, запущенном
через `serve`. Сравнение с коммитом или индексом можно читать, но комментировать
можно только конечное состояние `working-tree`. В статической сборке,
переводном портале и при прямом запуске каталога перевода этого экрана нет.
