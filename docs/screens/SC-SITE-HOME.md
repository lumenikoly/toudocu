# SC-SITE-HOME: Главная портала

- Идентификатор: SC-SITE-HOME
- Тип: Страница
- Модуль: MOD-SITE
- Статус: Реализован
- Маршрут: `/`
- Превью: `../assets/screens/site-home.png`
- Последнее обновление: 2026-08-08

Главная точка входа в собранную документацию оформлена как паспорт проекта:
обложка с названием, описанием и metadata сменяется одной строкой состояния,
тремя–пятью рекомендуемыми маршрутами и постоянно видимым полным обзором
`index.md`. Строка состояния выбирает переход в порядке `status.md` → документ
ближайшего результата → каталог работ → риски. Описание из обложки повторно в
обзоре не показывается, а действия контекста и serve-действия находятся в его
заголовке. Главная ведёт к документам, локальному редактору, просмотру изменений
и HTTP API. В
canonical `serve` под header может появиться компактное неблокирующее
предложение открыть более новый официальный релиз Toudocu; его можно скрыть
для указанной версии.
