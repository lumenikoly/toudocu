# SC-SITE-API-DOCS: HTTP API

- Идентификатор: SC-SITE-API-DOCS
- Тип: Экран
- Модуль: MOD-SITE
- Статус: Реализован
- Маршрут: `/_toudocu/api-docs/`
- Превью: `../assets/screens/site-api-docs.png`
- Последнее обновление: 2026-08-10

Страница доступна только при `serve` и показывает OpenAPI-контракты редактора и
раздела «Изменения». Пользователь выбирает контракт, раскрывает нужную операцию
и видит путь, параметры, ответы и схему данных. Из интерфейса можно выполнить
только безопасные запросы `GET` и `HEAD` к тому же локальному серверу.

## Переходы

Отдельных переходов карты экранов здесь нет. Назад пользователь возвращается
обычной кнопкой браузера или ссылками общей панели рабочего пространства.
