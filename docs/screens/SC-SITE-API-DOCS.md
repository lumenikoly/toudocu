# SC-SITE-API-DOCS: HTTP API

Страница доступна только при `serve` и показывает OpenAPI-файлы выбранного
проекта. Пользователь выбирает контракт,
раскрывает нужную операцию и видит путь, параметры, ответы и схему данных. Из
интерфейса можно выполнить только `GET` и `HEAD`. Адрес сервера берётся из
спецификации; перед запросом проверьте, куда он будет отправлен.

## Переходы

Отдельных переходов карты экранов здесь нет. Назад пользователь возвращается
обычной кнопкой браузера.
