# SC-SITE-EDITOR: Редактор

Редактор исходной документации доступен по адресу `/_toudocu/editor/` только в
режиме `serve`. Здесь можно выбрать или создать разрешённый файл, изменить его,
посмотреть результат Markdown и безопасно сохранить правку.

## Оболочка и состояния

Верхняя панель ведёт в портал, редактор и раздел «Изменения» и позволяет выбрать
оформление. Ниже находятся текущий путь, список файлов, действия создания и
сохранения и ссылка на исходник.

Список файлов отображается как дерево каталогов любой глубины. Все каталоги
сначала раскрыты; пользователь может свернуть ветвь, и редактор сохраняет этот
выбор при обновлении списка в пределах открытой страницы. Фильтр ищет по полному
пути и заголовку, показывает только подходящие файлы и раскрывает ведущие к ним
ветви. Внутри каталога строка показывает только имя файла. Метка формата остаётся
у YAML- и JSON-файлов, а у Markdown-файлов не выводится.

Выбранные тема (`classic`, `paper` или `terminal`) и цветовая схема (`system`,
`light` или `dark`) применяются сразу и сохраняются для других рабочих экранов.
Переключение не стирает выделение, историю отмены и несохранённый текст. На
узком экране список файлов открывается отдельной панелью без горизонтальной
прокрутки всей страницы.
