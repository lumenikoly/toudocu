# SC-SITE-DOCUMENT: Страница документа

- Идентификатор: SC-SITE-DOCUMENT
- Тип: Страница
- Модуль: MOD-SITE
- Статус: Реализован
- Превью: `../assets/screens/site-document.png`
- Последнее обновление: 2026-08-06

Каноническое представление выбранного Markdown-документа в портале. Конкретный
URL определяется самим документом и generated output, поэтому общий шаблон
маршрута здесь намеренно не фиксируется. Для `risks.md` страница дополнительно
показывает понятную текстовую сводку статусов, незакрытое количество и ход
выполнения мер снижения; статусы риска и чек-листы мер отображаются раздельно.
Для `roadmap.md` canonical `serve` добавляет доступный диалог создания одного
незавершённого `DLV-*` в существующем этапе. Диалог является состоянием этой
страницы, а не отдельным экраном или навигационным переходом; static и locale
представления его не содержат.
