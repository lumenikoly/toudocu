# Стандарты качества


Здесь собраны обязательные правила разработки и ведения документации Toudocu.
Каждый стандарт действует только в области, указанной в его метаданных. Сам
стандарт не задаёт команды для `task verify`: такие команды принадлежат
конкретной рабочей задаче.

- [STD-GO-001: исторические правила удалённой Go-реализации](STD-GO-001.md)
