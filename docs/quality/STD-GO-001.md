# STD-GO-001: Качество Go-кода

- Идентификатор: STD-GO-001
- Статус: Действует
- Владелец: Команда Docgent
- Область: Go-код и тесты репозитория
- Последнее обновление: 2026-07-31

Стандарт сохраняет реализацию Docgent небольшой, предсказуемой,
dependency-free и проверяемой на поддерживаемых Go-платформах.

## Правила

1. Не добавлять внешнюю зависимость без доказанной необходимости.
2. Сохранять обратную совместимость с вызовом `docgent ./docs ...`.
3. Каждое новое правило валидации сопровождать поведенческим тестом.
4. Каждое исправление безопасности сопровождать негативным тестом.
5. Не ослаблять проверки `repository-root` и безопасного `--clean`.
6. Сохранять обычные `check`, `build`, `serve` и `task context`
   неисполняющими команды work item.

## Автоматические проверки

- `gofmt -w .`;
- `go vet ./...`;
- `go test ./...`;
- `go test -race ./...`.

Команды запускаются из work item или доверенного CI workflow, а не напрямую из
этого стандарта.
