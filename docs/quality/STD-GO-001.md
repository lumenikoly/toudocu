# STD-GO-001: Качество Go-кода

- Идентификатор: STD-GO-001
- Статус: Действует
- Владелец: Команда Docu-docu
- Область: Go-код и тесты репозитория
- Последнее обновление: 2026-08-06

Стандарт сохраняет реализацию Docu-docu небольшой, предсказуемой,
автономной и проверяемой на поддерживаемых Go-платформах.

## Правила

1. Не добавлять внешнюю зависимость без ADR, закреплённой версии, notices,
   проверки лицензии и доказанной необходимости. Pure-Go dependency должна
   сохранять автономный binary и CGO-disabled cross-build.
2. Публичные операции вызываются только явными командами; путь без команды не
   запускает неявный `build`.
3. Каждое новое правило валидации сопровождать поведенческим тестом.
4. Каждое исправление безопасности сопровождать негативным тестом.
5. Не ослаблять проверки `repository-root` и безопасного `--clean`.
6. Сохранять обычные `check`, `build`, `serve` и `task context`
   неисполняющими команды work item.

## Автоматические проверки

- `gofmt -w .`;
- `go vet ./...`;
- `go test ./...`;
- `go test -race ./...`.
- `go mod verify`;
- CGO-disabled cross-build поддерживаемых целей.

Команды запускаются из work item или доверенного CI workflow, а не напрямую из
этого стандарта.
