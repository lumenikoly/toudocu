- Статус: В работе
- Этап: Полная реализация документной модели и визуального портала
- Версия: 1.1.0-go
- Владелец: Команда Docgent
- Последнее обновление: 2026-07-30

Основные пользовательские потоки реализованы и покрыты автоматическими
проверками; текущий фокус — стабилизация контракта и подготовка следующего
релиза.

## Краткое состояние

CLI проверяет, собирает и локально раздаёт документацию, формирует
типизированные JSON-отчёты, выдаёт контекст выбранной задачи и выполняет её
проверки только по явной команде. Встроенная Mermaid Tiny отображает связанные
процессы без CDN или Node.js. Безопасность путей, HTML, диаграмм, HTTP-раздачи
и process timeout проверяется негативными тестами.

Модель процессов формирует раздельные каталоги `UC-*` и `FLOW-*`, стабильные
URL по ID и рабочее пространство use case с описанием, картой, проигрыванием и
связями. Экранная модель формирует основной каталог, отдельную общую карту с
SVG-связями, sitemap, hotspots и traceability. Всё работает через `file://`,
поддерживает клавиатуру, touch, состояния, ошибки и fallback без preview.

Активные задачи, блокеры и следующий результат вычисляются из work items и
roadmap и отображаются в HTML автоматически.

## Готовность

Исходный код и встроенные assets находятся в одном Go-модуле без внешних
зависимостей. Обычные и race-тесты, vet, strict-проверка собственной
документации и Windows cross-build проходят.

## Следующий фокус

Подготовить воспроизводимый релиз после проверки обратной совместимости и
публичных JSON-контрактов.
