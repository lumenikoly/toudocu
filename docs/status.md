Версия `0.0.1` готовится к стабильному релизу вместе с проверяемыми POSIX- и
PowerShell-installers, release workflow, checksums и документацией установки.

## Краткое состояние

CLI проверяет, собирает и локально раздаёт документацию, формирует
типизированные JSON-отчёты, выдаёт контекст выбранной задачи и выполняет её
проверки только по явной команде. Корневой Go-пакет предоставляет стабильный
фасад модели, рендеринга и отчётов для локального встраивания; канонический
удалённый module path пока не опубликован. Встроенная Mermaid Tiny отображает
связанные процессы без CDN или Node.js. Безопасность путей, HTML, диаграмм,
HTTP-раздачи и process timeout проверяется негативными тестами.

Модель процессов формирует раздельные каталоги `UC-*` и `FLOW-*`, стабильные
URL по ID и рабочее пространство use case с описанием, картой, проигрыванием и
связями. Экранная модель формирует основной каталог, отдельную общую карту с
SVG-связями, sitemap, hotspots и traceability. Всё работает через `file://`,
поддерживает клавиатуру, touch, состояния, ошибки и fallback без preview.

Активные задачи, блокеры и следующий результат вычисляются из work items и
roadmap и отображаются в HTML автоматически.

## Готовность

Исходный код и встроенные assets поставляются одним бинарником без внешних
runtime-зависимостей. Закреплённая Go-зависимость для OpenAPI YAML связывается
внутрь бинарника. Форматирование, обычные и race-тесты, vet, проверка модулей,
strict-проверка обоих documentation roots и пять cross-build проходят через
единый `make check` / `make release` workflow. Release bundle включает два
installer-assets; они выбирают подходящий бинарник и проверяют его
SHA-256 до замены файла в user install dir.
