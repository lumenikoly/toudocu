# Текущее состояние

Готовится версия `0.0.8`; последний стабильный выпуск — `0.0.7`. Новый выпуск
использует TypeScript runtime и требует Node.js 24+. Установщики GitHub Release
для POSIX и PowerShell проверяют контрольную сумму перед заменой программы.

## Краткое состояние

CLI проверяет документацию, собирает портал и открывает его для локальной
работы. Он умеет выдавать JSON-отчёты и собирать сфокусированный контекст по
явно указанным связям выбранной задачи, но запускает её проверки только по
явной команде. CLI и HTTP используют общие TypeScript application-сценарии.
Диаграммы Mermaid работают без CDN. Тесты отдельно проверяют опасные пути,
HTML, диаграммы, HTTP-раздачу и ограничение времени выполнения команд.

Пользовательские сценарии `UC-*` и процессы `FLOW-*` собраны в отдельных
каталогах и доступны по постоянным адресам. Страница сценария показывает его
описание, карту, шаги и связи. Для экранов есть общий каталог, карта переходов,
вложенность, интерактивные области и таблица связей.
Статический портал работает через HTTP(S), поддерживает клавиатуру, сенсорное
управление и понятные состояния ошибок; для
локального просмотра используется `serve`.

Портал сам показывает активные задачи, препятствия и ближайший результат по
рабочим задачам и дорожной карте. В локальном разделе
«Изменения» реализованы просмотр файлов всего репозитория, фильтр по виду файла,
полный текст файла и те же обсуждения документации, что в Портале. Сообщение
не требует отдельной отправки: сохранение сразу создаёт запись очереди, которую
можно изменить или удалить до получения агентом.

Обсуждение само по себе не запускает агента. Отдельно от него основной
локальный `serve` предоставляет Agent Console: готовую задачу можно передать
установленному Codex или OpenCode, следить за разговором и командами, дополнять
поручение и явно остановить ответ или всю сессию. На опубликованном сайте и при
открытии `serve` для сети эта возможность отключена.

## Готовность

Готовый release-пакет требует Node.js 24+, но не требует Go, pnpm,
TypeScript, Python, `node-gyp` или compiler toolchain. `pnpm check` проверяет
форматирование, lint, строгую типизацию, unit/integration и compatibility tests,
а затем каноническую документацию. Отдельный browser suite проверяет React UI.
Release workflow собирает native PTY на Linux x64, macOS arm64 и Windows x64,
формирует npm tarball, архивы, checksums и notices, а затем устанавливает
готовый пакет в чистый каталог и запускает CLI/FS/Git/process/PTY smoke test.

## Следующий фокус

Выпустить `0.0.8` после полного цикла проверок и установки готового пакета
на Linux x64, macOS arm64 и Windows x64. Публикация GitHub Release выполняется
отдельным явным запуском release workflow из `main`; публикации в npm registry нет.
