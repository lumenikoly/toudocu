РЯДОМ С КОДОМ.

Проверяйте и редактируйте Markdown, разбирайте изменения в Git и передавайте задачи агенту. Всё в локальном портале.

#Проверить структуру, ссылки и связи
$toudocu check ./docs
#Открыть локальный портал с редактором
$toudocu serve ./docs
#Собрать статический сайт для публикации
$toudocu build ./docs --output ./site

Возможности Toudocu

ДЛЯ ИНЖЕНЕРОВ

Находите архитектуру, требования и задачи в том же репозитории, где лежит код.

ДЛЯ АВТОРОВ ДОКУМЕНТАЦИИ

Правьте Markdown в браузере, проверяйте ссылки и публикуйте документацию.

ДЛЯ АГЕНТОВ

Получайте требования, зависимости и правила для выбранной задачи.

ПРОВЕРКА ДОКУМЕНТАЦИИ

НАХОДИТЕ БИТЫЕ СВЯЗИ.

Находите битые ссылки и ошибки в документах перед публикацией. Точность описаний по-прежнему нужно проверять вручную.

ПУБЛИКАЦИЯ

ПУБЛИКУЙТЕ КАК САЙТ.

Соберите сайт с поиском и диаграммами для GitHub Pages или другого статического хостинга. Читателям не нужен Toudocu.

КОМАНДЫ CLI

ПРОВЕРИТЬ. СОБРАТЬ. ЗАПУСТИТЬ.

Проверьте документы, соберите сайт для публикации или откройте локальный портал.

  1. CHECKtoudocu check ./docs --strict
  2. BUILDtoudocu build ./docs --output ./site --clean
  3. SERVEtoudocu serve ./docs

РЕВЬЮ ИЗМЕНЕНИЙ

СМОТРИТЕ, ЧТО ИЗМЕНИЛОСЬ.

ЧТО МОЖНО ДЕЛАТЬ.

Документы остаются файлами в Git. Toudocu помогает читать, проверять и обновлять их.

01

ПРОВЕРЯЙТЕ

Находите ошибки в документах и ссылках. Запускайте проверку вручную или при сборке проекта.

toudocu check ./docs
02

ПУБЛИКУЙТЕ

Собирайте сайт для чтения с поиском, диаграммами и ссылками между требованиями, задачами и решениями.

toudocu build ./docs
03

ПРАВЬТЕ

Редактируйте документы прямо в браузере. После сохранения сразу видны результат и найденные ошибки.

toudocu serve ./docs
04

СРАВНИТЕ

Сравнивайте текст, диаграммы и API до и после правки. Смотрите, какие задачи затронуты.

toudocu changes ./docs
05

СТРОЙТЕ КАРТУ

Смотрите, как связаны экраны приложения. Проходите пользовательские сценарии шаг за шагом.

screens/SC-*.md
06

ОБСУЖДАЙТЕ

Оставляйте вопросы и просьбы о правках рядом с текстом. Попросите агента разобрать их — ответ появится в том же обсуждении.

Обсуждения в локальном портале
07

РАБОТАЙТЕ С АГЕНТОМ

Передавайте агенту задачу вместе с требованиями, правилами проекта и шагами проверки.

toudocu task context TASK-ID ./docs
08

ОБНОВЛЯЙТЕ

Попросите агента обновить документацию после изменений в коде.

$toudocu refresh diff

С ЧЕГО НАЧАТЬ.

Подключите Toudocu к своему агенту по шагам ниже. Уже есть документация? Откройте её командой toudocu serve ./docs.

  1. 01

    НАВЫК

    toudocu skill install --agent codex

    В корне проекта подключите навык к Codex. Также поддерживаются Claude Code и GitHub Copilot.

  2. 02

    ФАЙЛЫ

    $toudocu init

    Отправьте это сообщение агенту с навыком. Он изучит репозиторий и создаст документацию.

  3. 03

    ПРОВЕРКА

    toudocu check ./docs

    Запустите проверку в терминале и прочитайте созданные документы.

  4. 04

    ПОРТАЛ

    toudocu serve ./docs

    Перейдите по ссылке из терминала. Читайте и редактируйте документы в браузере.

  5. 05

    ПРАВКИ

    $toudocu refresh diff

    После изменения кода отправьте это сообщение агенту, чтобы обновить связанные документы.
