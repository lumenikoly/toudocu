# AGENTS.md

## Назначение

Toudocu — dependency-free Go CLI. Сохраняйте реализацию небольшой, предсказуемой и безопасной.

## Навигация

- правила Go-кода и обязательный цикл проверки:
  [`STD-GO-001`](docs/quality/STD-GO-001.md);
- правила исходной документации, generated output и semantic review:
  [`STD-DOCS-001`](docs/quality/STD-DOCS-001.md);
- эксплуатационные процедуры: `docs/runbooks/`, только если раздел существует
  и содержит реальный `RB-*`;
- неизвестный верхнеуровневый раздел с Markdown: собственный `index.md` с
  `Тип: Custom`, владельцем и описанием;
- архитектура и источники истины:
  [`docs/architecture/overview.md`](docs/architecture/overview.md);
- workflow work items: [`docs/guides/work-items.md`](docs/guides/work-items.md).

Перед изменением просмотрите явно связанные стандарты и runbook, затем
проверьте `Область` остальных стандартов. CLI намеренно не угадывает
применимость по glob.

`docs/architecture/overview.md` обязателен. Каждый другой Markdown-файл под
`architecture/` отвечает на один явный архитектурный вопрос и добавляется в
overview прямой ссылкой, включая вложенные каталоги. Подробные взаимодействия,
контракты, справочные факты, процедуры, причины решений и локальные правила
остаются соответственно в FLOW, CONTRACT, REFERENCE, RUNBOOK, ADR и MODULE.

Для систематического обновления используйте `$toudocu refresh` по всей
исходной документации или `$toudocu refresh diff` для staged, unstaged и
untracked изменений относительно `HEAD` вместе с зависимыми документами. Оба
режима изменяют документацию, не являются командами Go CLI и не выполняют init.

## Изоляция переводов

Канонический documentation root — единственный источник обычного
документационного, implementation и task-контекста. Настроенные translation
roots исключаются из репозиторного поиска, инвентаризации, semantic review,
анализа реализации и task context, включая переведённые work items.

Выбранный translation root разрешено читать только при явном `$toudocu
translate <locale>` или явном запросе проверить, найти, собрать, запустить или
изучить конкретную локаль. Явный `$toudocu translate diff` разрешает
последовательно обработать все настроенные translation roots. Читайте одну
необходимую source/target-пару за раз; для проверки паритета сначала используйте
пути, хеши и структурные отчёты. Не добавляйте translation roots в `.gitignore`
или глобальные ignore-файлы.

Если в корне репозитория есть `CHANGELOG.md`, это единственный специальный
журнал релизных изменений: портал показывает его как «Журнал изменений
проекта». Не создавайте дублирующий `docs/changelog.md`; такой файл остаётся
обычным Markdown-документом без специальной семантики. Не создавайте корневой
журнал только ради вкладки.
