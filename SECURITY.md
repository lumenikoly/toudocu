# Security Policy

## Сообщение об уязвимости

Не публикуйте рабочий эксплойт в открытом issue. Передайте описание сопровождающим проекта через приватный security advisory репозитория.

Укажите:

- версию Docgent;
- операционную систему;
- минимальный Markdown-вход;
- ожидаемое и фактическое поведение;
- влияние на чтение файлов, генерацию HTML или удаление каталогов.

## Границы безопасности

Особенно чувствительны:

- обход `--repository-root`;
- небезопасная очистка каталогов;
- внедрение HTML/JavaScript через Markdown;
- копирование активных ресурсов;
- символические ссылки;
- опасные URL-схемы.
