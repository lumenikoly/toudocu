# UC-CORE-01: Основной пользовательский сценарий

- Идентификатор: UC-CORE-01
- Статус: В работе
- Актор: Пользователь
- Модуль: MOD-CORE
- Приоритет: Высокий
- Последнее обновление: {{DATE}}

Пользователь получает основной результат проекта.

## Цель

Получить проверяемый результат после одного понятного действия.

## Входные данные

- Валидный пользовательский запрос.

## Предусловия

- Система доступна.

## Основной сценарий

1. Пользователь отправляет запрос.
2. Система проверяет входные данные.
3. Система возвращает результат.

## Альтернативные сценарии

При неверных данных система возвращает понятную ошибку и не изменяет состояние.

## Постусловия

При успехе результат создан; при ошибке состояние не изменено.

## Бизнес-правила

- BR-CORE-001 — правило проверки входных данных.

## Критерии приёмки

- [ ] Валидный запрос возвращает ожидаемый результат.
- [ ] Невалидный запрос не изменяет состояние.
