# ADR-007: Code highlighting is available only in `serve`


The Changes workspace highlights Go, Java, JavaScript, and TypeScript. Other
text files are still available as plain UTF-8 text.

<!-- toudocu:section context -->
## Context

Changes displays Markdown and arbitrary repository files. CodeMirror already
supports Markdown, JSON, and YAML, but reading source code also benefits from
language-aware highlighting. That support must work without a CDN or a new Go
dependency. Bundling every language would substantially increase the embedded
asset and make updates more expensive.

<!-- toudocu:section decision -->
## Decision

Pin direct dependencies on `@codemirror/lang-go@6.0.1`,
`@codemirror/lang-java@6.0.2`, and
`@codemirror/lang-javascript@6.2.5`. The last package supports JavaScript, JSX,
TypeScript, and TSX when the corresponding mode is selected. Every other valid
UTF-8 file opens in the read-only editor without a language parser; selection
and comments work in the same way.

The language packages are included only in the CodeMirror asset used by
`serve`. The asset build updates the generated file, license information, and
checksum. Static portals do not receive these packages.

<!-- toudocu:section consequences -->
## Consequences

- Go, Java, JavaScript, and TypeScript are syntax-highlighted, but comment
  coordinates do not depend on the language.
- Every other UTF-8 file can still be viewed and commented on.
- The embedded asset is larger but remains self-contained and reproducible.
- Versions and licenses change only through an intentional frontend dependency
  update.
