# ADR-003: Use a maintained YAML parser for OpenAPI


Toudocu uses one pinned Go YAML module for reliable OpenAPI parsing. It is
compiled into the self-contained binary.

<!-- toudocu:section context -->
## Context

The parser for `.toudocu/config.yml` intentionally supports only the subset of
YAML required by project configuration. OpenAPI also needs nested mappings and
sequences, anchors, aliases, flow-style values, and exact source locations.
Building that full parser in this project would add more complexity and risk
than using an established implementation.

<!-- toudocu:section decision -->
## Decision

Pin `go.yaml.in/yaml/v3` at `v3.0.5` and decode OpenAPI into `yaml.Node`. Limit
document size, depth, aliases, and internal `$ref` processing. Never download
external references. Keep the version, license, checksums, and notices in the
repository, and review security advisories when updating it.

<!-- toudocu:section consequences -->
## Consequences

- Runtime operation remains offline and delivery remains one Go binary.
- ADR-001 gains one explicitly documented Go-module exception.
- YAML and JSON OpenAPI inputs produce one structured representation with line
  and column positions.
- Updating the module requires a separate compatibility and security review.
