# ADR-002: Limitation of responsibility between Agent and Docu-docu

- Identifier: ADR-002
- Status: Accepted
- Date: 2026-07-29
- Author: Docu-docu Team
- Last updated: 2026-07-29

The solution fixes the boundary between the deterministic mechanics of the CLI and the semantic one
the work of the performer.

## Context

Task preparation starts with natural language, but the documentation model
should remain reproducible and testable without LLM or network service.
Automatic creation of connections, requirements and statuses would make the framework
unreliable source of truth.

## Decision

Docu-docu performs only deterministic operations: lexical search,
ID allocation, creation of neutral wireframes, structural readiness check,
collecting context and explicitly launching declared verification commands.

The executor interprets the request, selects entities, fills out documents,
formulates requirements and criteria, changes statuses and marks `[x]` only after
actual evidence. Docu-docu does not perform these actions automatically.

## Consequences

- CLI remains dependency-free and reproducible;
- frameworks do not invent connections, topology or business rules;
- readiness remains read-only;
- the quality of meaning requires agential or human verification;
- natural-language orchestration is outside the Docu-docu public contract.
